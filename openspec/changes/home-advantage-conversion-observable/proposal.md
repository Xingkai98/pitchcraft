# 改进提案：主场优势的短窗口方向观测量（进球 → 转化率）

## Why

`l1_home_away_goal_asymmetry` 的短窗口方向 sanity 断言 `gh > ga`（**进球数**方向）。
跨窗体检（`.scratch/notes/p-landmine-check-2026-10-15/REPORT.md`，pristine `784cdd9`，7×200 场不重叠块）
判定它是**地雷**：

- 冻结窗（600 场）只赢 **16 球（0.9%）**，ratio 95% CI **[0.928, 1.118] 跨 1**；
- 200 场粒度 **7 块里 4 块方向为负**；1400 场点估计 **H/A = 0.986 < 1**。

**根因是量选错了，不是机制坏了**：进球是「射门量 × 把握率」的**复合量**，而主场优势在本引擎里
由**只改把握的那条通道**实现（`CLINICAL_GOAL_PP_HOME`，主队 goal 窗口 +2pp）。实测两个分量：
**客队射门本就多 12.6%**（1400 场 17675 : 15693，7 块无一例外），把主队的把握优势稀释掉了。
同一批比赛换成**转化率**看，主队 **0.12662** vs 客队 **0.11400**（差 +1.26pp、z≈3.5）——
通道按声明值在工作。

## What Changes

- **断言换观测量**：`l1_home_away_goal_asymmetry` 的方向 sanity 由「主队进球 > 客队进球」
  改为「**主队转化率 > 客队转化率**」（冻结窗 401..1000 实测 0.13122 vs 0.11642，差 +1.48pp、**z = 2.68**）。
- **口径**：转化率 = `n_goal_home/away ÷ n_shot_home/away`，**含头球**（头球同走 +2pp 窗口，
  与既有 `n_goal_home/away` 同口径）。为此在 `aggregate` 里新增按队射门计数
  （`n_shot_home` / `n_shot_away`，两行）。
- **窗不变**：预注册冻结窗 401..1000（600 场）不动——按本仓纪律，窗不得因「跑不过」而调整。
- **绝对量带与客队下界不变**：主队进球/场 ∈ [0.85, 1.60]、客队进球/场 ≥ 0.30、样本量前置守卫均保留。
- **进球方向不丢**：H/A 点估计与 CI 仍由 `l3_home_away_goal_calibration`（report-only）输出，
  只作为**观察**，不再作为硬门。

## 顺带的记录订正（同行同 change）

`realism.rs` 里 `far == 0`（抢断）的 ε 注释**依据已过期**：它写「pristine 自己在 seed 窗
1001/1201/1401/1601/1801 上破」，但当前树按**裸 12.0 口径**重测 7 块（含那五个窗）**全为 0**、
实测最大事件内距离仅 **1.8849 m**（距阈值 10.12 m），与同文件 #104 自记的「干净 main 3000 场 0 越界」
一致。⇒ **断言与 ε 保留**（仍守「资格在打分阶段判定」），**只订正注释**。

## 不做

- 不改任何**绝对量带**、不改 `SEEDS_HA`/窗、不动机制（`CLINICAL_GOAL_PP_HOME` 等常量一字不改）。
- 不修 `禁区内进球占比`（真回归 + 尺子 y-blind）——那是**另一个 change**（处方见
  `.scratch/notes/gate-landmines-2026-10-14.md` §3）。
