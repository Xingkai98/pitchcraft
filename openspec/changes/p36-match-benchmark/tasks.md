## P2. 基线与对比

- [x] P2.1 真实侧基线生成：多场 × 多窗口 → 观测范围摘要（min/max + 均值 + 样本量），入库
      - 同时生成**引擎侧 ratchet 冻结基线**（冻结种子集的当前值）
      - 路径 `viewer/data/benchmark-baseline.json`；体积数百字节量级；原始数据不入库（P35 已定）
      - **必须记录**：样本量（13 个满窗 / 2 场）、每窗实际时长（game2 末窗仅 246s）、
        数据来源、未覆盖维度声明、指标模块版本（陈旧性校验）
      - 记录完整重生成链路（fetch → convert → 基线生成），否则"可复现"只是口号
- [x] P2.2 `tools/benchmark-compare.mjs`：跑引擎侧采样 → 与基线对比 → 输出报告
      - **默认 = 报告期**（不产生 pass/fail，见 design D5b 与用户拍板）
      - 输出：三项采用指标数值 + 偏离真实范围的方向与幅度 + 报告项 + 口径敏感性对照
      - 断言只存在于 P1.4 的指标单测（保证测量可靠，不判定符合性）
- [x] P2.3 对比逻辑单测：数值输出正确 / 越界给出偏离方向与幅度 / 基线缺失时跳过并提示
- [x] P2.4 `verify.sh` 纳入（无真实基线时跳过而非失败）
