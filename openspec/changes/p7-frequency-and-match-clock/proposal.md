# Proposal: 频率调优 + 90 分钟比赛 + 观看时长控制（frequency-and-match-clock）

## Why

P6 批次1 完成后用户验收反馈：

1. **死球重开频率偏低**：按 90 分钟基准角球 ~1.4 次、界外球 ~8 次、头球 ~1 次，远低于真实比赛（角球 10-13、界外球 30-40、头球数十次）。
2. **比赛时间控制机制**（用户澄清）：**比赛内容 = 90 分钟真实比赛**（引擎模拟 5400s，球员移动真实速度）；**观看时长可调**（5/10 分钟等）——播放压缩到这个时长看完 90 分钟；**时间显示按比赛时钟 0-90 分钟**（如 45:00 显示上半场结束）。

## What Changes

- **引擎默认 90 分钟**：`MatchConfig::default_()` 2700 → 5400（`match_duration_seconds` 仍可由调用方覆盖，即观看时长与比赛内容解耦）。
- **频率调优**（90 分钟基准，接近真实比赛）：
  - 角球：saved-rebound 越线概率 30% → 80%、扑出率 30% → 50% → 角球 ~6-9 次/场（真实 10-13，画面死球密度权衡）。
  - 界外球：传球出界率 3-5% → 8-10%，且出界以边线为主（边线 ~65%）→ 界外球 ~17-21 次/场。
  - 头球：随角球增多自然提升（角球争抢 + 解围 ~8-12 次/场）。
  - 进球：goal 率 15% → 9%（射门增多后避免比分过高）→ ~3-3.5 球/场。
- **观看时长控制**（viewer）：
  - 观看时长可配置（默认 5 分钟，UI 循环 5/10/20/45/90），播放基速 = 比赛总秒 /（观看时长×60）。
  - 时间显示 = 比赛时钟 `MM:SS / 90:00`（playTime 即比赛秒，直接格式化为比赛时间）。
  - 速度档位在观看时长基础上再乘（1x/2x/4x）。

## Capabilities

### New Capabilities

- **90 分钟完整比赛**：引擎默认产出 90 分钟事件流。
- **比赛时间显示**：显示比赛时钟 `MM:SS / 90:00`（从 0 走到 90:00）。
- **观看时长控制**：5/10/20/45/90 分钟看完 90 分钟比赛，球员移动真实速度（引擎固定 tick 不变，仅播放加速）。

### Modified Capabilities

- `match-engine`：默认时长 5400s；死球重开频率调优（角球/界外球/头球来源概率）。
- `pitch-viewer`：时间显示格式（比赛时钟）、观看时长配置、速度档位。

## Impact

- 引擎：`MatchConfig::default_()` 时长、`emit_pass_highlight` 出界率与边线/底线拆分、`emit_shot_highlight` goal/扑出/越线概率、`emit_header_shot` 同。
- viewer：app.js 时间格式 + MATCH_CONFIG 5400 + 观看时长按钮、config.js 播放配置、game.js 基速计算、index.html 版本号。
- 测试：引擎测试适配 5400s 与新频率区间；viewer 时间格式测试；e2e 全场步进（5400s）。
