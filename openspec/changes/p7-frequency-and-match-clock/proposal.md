# Proposal: 比赛时长可调 + 精彩事件固定产出 + 跳过机制（match-duration-and-skip）

## Why

P6 批次1 完成后用户验收反馈：死球重开频率偏低 + 比赛时间控制机制需借鉴 FM 的跳过机制。

用户讨论定稿（2026-08-09）：
1. 比赛时长参数可调（5/10/45/90 分钟）。
2. **精彩事件固定产出**——不管时长，每场固定 ~40 个核心精彩事件；5 分钟 = 精华集锦密集，90 分钟 = 同样内容 + 大量非精彩段。
3. **跳过机制**——非精彩段（仅 beat 无高亮）播放时快速播放（5x/10x）或直接跳过（屏幕选项），非精彩 beat 保留（球员位置连贯）。
4. 时间显示跟随比赛时长刻度（5 分钟 → 00:00-05:00；90 分钟 → 00:00-90:00），跳过段时钟跳。
5. 指标稳定：不同时长下精彩内容相同。

## What Changes

- **引擎槽位机制**：高亮产出从概率门控改为槽位驱动——比赛时间均匀划分 `HIGHLIGHTS_PER_MATCH`（~40）个槽位，每槽必产一个高亮；高亮类型固定比例（射门 30%/抢断 15%/普通传球余下）；派生概率固定（出界率、扑出越线率）。
- **时长参数可调**：`match_duration_seconds` 由 app 提供 5/10/45/90 分钟选项。
- **viewer 跳过机制**：高亮间隙检测（> 阈值进入跳过模式）；跳过选项（快速播放 5x/10x / 直接跳过）；时间显示跟随 matchEnd 刻度。
- **比赛时钟显示**：00:00 → matchEnd（5 分钟显示到 05:00，90 分钟显示到 90:00）。

## Capabilities

### New Capabilities

- **比赛时长可调**：引擎事件流时间范围随参数（5/10/45/90 分钟）。
- **精彩事件固定产出**：每场固定 ~40 核心高亮，指标不随时长漂移。
- **跳过机制**：非精彩段快速播放或直接跳过（屏幕选项）。

### Modified Capabilities

- `match-engine`：槽位驱动高亮（roll_highlight 改 hold_max 固定 + 派生概率固定）。
- `pitch-viewer`：时间显示跟随 matchEnd、跳过机制（间隙检测 + 选项）。

## Impact

- 引擎：`roll_highlight` 槽位驱动、`emit_pass_highlight` 出界率固定、`emit_shot_highlight` saved/越线概率固定、`HIGHLIGHTS_PER_MATCH` 常量。
- viewer：app.js 时长选项 + 跳过 UI + 时间显示；game.js 跳过检测 + 跳过模式；config.js 跳过配置。
- 测试：引擎频率断言（5 分钟 vs 90 分钟产出相同精彩事件数）；viewer 跳过测试。
