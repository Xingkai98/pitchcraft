# 真实球员的横向位置由什么驱动

> **本文件是测量报告，回答 wayfinder #101。** 每条结论带**数字 + 样本量 + 脚本路径**。
> 第 8 节明确写出**仍然未知的部分**。
>
> **样本升级**：P38 #90 用 SkillCorner **6 场**；本报告用 **20 场全量**（879,080 人·采样点，
> 400 个「场·队·人」单元）。口径经对账确认与 #90 一致（§0.2）。

---

## 0. 结论速览

| # | 结论 | 证据强度 |
|---|---|---|
| 1 | **球位几乎不驱动个体横向位置**（alone R² **0.029**）——#101 的起点事实，20 场确认 | **强**（与 `mechanism-exploration` 的 0.167 同向，口径差异见 §1.4） |
| 2 | **最强的同时刻驱动是"周围人的横向位置"**（k3AnyY **0.704**、k3MateY 0.643、k3OppY 0.444） | **强**（置换零分布 ~0.001，**1050–1330×** 分离，探针 6） |
| 3 | **但这些驱动是同一个共同因子**：PC1 单独解释 DV 的 **0.728**，载荷全在"队友/邻域/对手"簇上 | **强**（探针 7） |
| 4 | **给定全部当帧上下文，y 的可预测性上限 = 0.886**（GBM 泛化读数；线性 0.820） | **强**（按场分组留出，安慰剂 −0.914） |
| 5 | **位置是极强惯性慢变量**：上一时刻的同一个 y 单独解释 **0.933**；**加上惯性后上限 0.985** | **强**（探针 1、探针 2 §2.3） |
| 6 | **个体性三层分解**（pooled 口径）：静态档位 56.4% / 情境响应 25.3% / 个体残差 18.3% ⚠ **与 §2 的 R² 不是同一聚合，不可对账**（§5.5） | **强**（打乱对照 932×） |
| 7 | **#101 的预设被推翻**：上限**不低**（0.89），故横向**没有**大量"自由成分" | **强**（见下） |
| 8 | **球门方向、纵向×相位交互、运动学速度**：全部 ≤ 0.036，**不是驱动** | 强 |

**一句话**：横向**不是**被球或某个标量驱动的，而是被**周围人构成的局部结构 + 强惯性**驱动；
且这两者合起来能解释 **~89%（当帧）/ 98.5%（含惯性）**——
**信号是充足的，横向并不"自由"**。引擎的缺口不是"不可约的随机性"，而是
**根本没接这两个信号**（`formation_target` 只读球位与静态模板）。

> ⚠ **对 #101 提问方式的一处修正**：#101 正文第 2 条预设"如果上限本来就不高，
> 说明横向有大量'自由'成分"。**实测上限不低**（0.886）——所以这个分支不成立。
> 真正的结论更有利于 #89：**不需要发明新信号，只需要用对已有的两个**
> （局部相对结构 + 上一拍的自己）。

## 1. 换一组候选驱动：什么能解释足够多

**探针**：`probes-main/issue101-1-drivers.mjs` → `out/101-1-drivers.txt`

### 1.1 单变量解释力阶梯（因变量 = `y_i − mateY`，留一队友重心）

| 因子 | 类别 | **alone R²** |
|---|---|---|
| `yPrev`（上一采样点的同一因变量） | 惯性 | **0.933** |
| `k3AnyY`（3 近邻[两队混池]的 y 均值） | 邻域 | **0.704** |
| `k5AnyY` | 邻域 | 0.667 |
| `k3MateY`（3 近队友的 y 均值） | 队友局部 | **0.643** |
| `k5MateY` | 队友局部 | 0.592 |
| `nearMateY`（最近队友） | 队友局部 | 0.522 |
| `k3OppY`（3 近对手） | 对手 | 0.444 |
| `nearOppY` | 对手 | 0.398 |
| `oppCy`（对手重心） | 对手 | 0.148 |
| `ballY` | **球** | **0.029** |
| `ballDepth` | 球 | 0.011 |
| `phase`（控球/失球） | 球 | 0.036 |
| `goalOwnY` / `goalOppY` | 球门方向 | 0.014 / 0.013 |
| `ownX`、`xXphase`、`ballXxPhase` | 纵向×相位 | 0.020 / 0.022 / 0.016 |
| `dyPrev`、`dxPrev` | 运动学 | 0.007 / 0.004 |

**四条读数**：

1. **横向位置是强惯性慢变量**（`yPrev` 0.933）。这是 #101 候选清单里
   （"时间维度：是否是慢变量——位置本身有惯性/持续性"）**最强的单项**，
   且 P38 #90 从未测过。
2. **最强的同时刻驱动是"周围人的横向位置"**（邻域/队友/对手，0.40–0.70）。
3. **球位最弱**（`ballY` 0.029）。⚠ 与 `mechanism-exploration` 报的 0.167 **不是矛盾**——见 §1.4。
4. **#101 点名的其余候选全部出局**：球门方向（≤0.014）、纵向×相位交互（≤0.022）、
   运动学速度（≤0.007）。**朝向不在数据里**（§5）。

### 1.2 多因子：全模型 R² 高，但每个因子的 unique R² 都 ≈ 0

| 因子 | alone R² | **unique R²** |
|---|---|---|
| `nearAnyDist` | 0.117 | **0.033** ⚠ 见下 |
| `k3AnyY` | 0.704 | **0.013** |
| `k3MateY` | 0.643 | 0.012 |
| `nearMateY` | 0.522 | 0.011 |
| （其余 10 个因子） | ≤0.444 | ≤0.009 |

**全模型 R² = 0.824**（14 个非自指因子，621,110 行）。

> **这是本报告最反直觉的结果**：模型能解释 82%，但**没有任何一个因子有独立的贡献**——
> 每个的 unique R² 都 ≤ 0.033。这不是"没找到驱动"，而是"找到的驱动**高度共线**"。
> 探针 7 解释了这件事（§3）：**它们的 PC1 就是同一个方向**。
> ⚠ 这里的 0.824 是**线性**、且用 14 个因子（含距离类）；§2 的 GBM 给出更高的 **0.886**。
> 两个数字不矛盾：GBM 捡到了线性模型捡不到的非线性。
>
> ⚠ **`nearAnyDist` 排在 unique 第一，但它更像共线性下的方差再分配，不是机制信号**：
> 它的 β = 0.002（≈ 2mm 每米——物理上"可忽略"的量级），单独 R² 只有 0.117，
> 却在一个强共线簇里拿到最大的 unique。**本报告没有对它做"打乱距离字段"的安慰剂对照**
> （第一轮审阅提出），故**不把它当结论**——它大概率只是吸收了那簇里未被线性抓取的部分。
>
> ⚠ **§1.1 表内各行用了不同的行集**（逐因子成列删除）：`ballY` 用 879,080 行、
> `phase` 只用 625,660 行。故**行间 0.001–0.005 的差没有意义**，读数精度到 2 位即可。
> （第一轮审阅指出；已核，不影响排序结论。）

### 1.3 ⚠ 方法学陷阱：自指因子会造出 R² = 1.0000（本探针踩过，留档）

因变量 `y = y_i − mateY`。而面板里的两个因子：

```
nearMateGap = y_i − y_最近队友
nearMateY   = y_最近队友 − mateY
⟹ nearMateGap + nearMateY ≡ y_i − mateY ≡ 因变量（精确恒等）
```

第一版把这两个都放进多因子模型 → 模型用系数 (1, 1) **精确重构**因变量，
测试 R² = **1.0000**，看起来是"横向 100% 可预测"的惊天结论，实为**同义反复**。

**规则（已写进 `issue101-panel.mjs` 的 `FACTORS` 注释与 `selfRef` 标记）**：
> **因变量含 `y_i` ⟹ 因子不得含 `y_i`。**

**⚠ 对手侧有同一个恒等式（审阅后补测，独立验证）**：
`nearOppGap = y_i − y_最近对手`、`nearOppY = y_最近对手 − mateY`，故
`nearOppGap + nearOppY ≡ y_i − mateY` **也是恒等式**。
实测最大误差 **7.1e-15**（与队友侧同量级，即浮点精度极限）。
故 `nearOppGap` 也已标 `selfRef`，同样不得进多因子模型。
**一般规则**：任何形如"`y_i` 减某个参照物"的因子，与"该参照物减 `mateY`"配对时都是恒等式。

距离量（`nearMateDist` 等）由本人位置算出，但**不是 `y_i` 的线性函数**，保留但标注。
`yPrev`（上一时刻的同一因变量）是**合法**的时序预测因子（时间上早于当前），
但必须单列在"时序预测"节（§2.3），不能混进"同时刻上下文"模型。

### 1.4 ⚠ 与既有数字的口径差异：为什么 `ballY` 是 0.029

⚠ **出处更正（审阅发现）**：第一版写"P38 #90 §1.1 报 0.167"——**#90 里没有 0.167**。
0.167 出自 `mechanism-exploration.md`（线 B 前置测量），那是
**Metrica 2 场**、**拼接全量回归**、DV = **绝对 y**——三个口径同时不同。

**要对比的正确数字是 #90 自己的 SkillCorner 个体层读数**：

| 来源 | 数据 | 因变量 | 聚合 | `ballY` alone R² |
|---|---|---|---|---|
| `mechanism-exploration.md` §1.1 | Metrica 2 场 | **绝对 y** | 拼接 | 0.167 |
| `probes-main/out/02-drivers.txt`（#90 个体层） | SkillCorner 6 场 | `y − mateY` | 逐人·场再平均 | **0.044** |
| **本报告** | SkillCorner 20 场 | `y − mateY` | 逐单元再平均 | **0.029** |

**0.044 → 0.029 才是同口径的对比**（差 34%，来自 6 场 → 20 场与聚合细节）；
0.167 → 0.029 之间隔着**数据集 + 聚合 + 因变量**三重差异。

**机制解释不变**：`probes-main/out/02-drivers.txt` 的队伍层表显示 `ballY` alone R² = 68.9%、
但个体层 unique R² = 0.3%——即"球位解释很多"**全部来自全队一起横移**，
在相对坐标系里归零（`real-lateral-laws.md` §2.2）。

> **要一起引用这两条**：球位对**球队重心**有 0.33–0.39 的斜率（`real-lateral-laws.md` §1.1），
> 对**个体相对位置**只有 0.029–0.044。**"全队跟球"与"个人跟球"是两件事**。

## 2. 换个建模方式：y 的可预测性上限

**探针**：`probes-main/issue101-2-ceiling.mjs` → `out/101-2-ceiling.txt`

**协议**：**leave-one-match-out**（训练 19 场、测试留出 1 场）——
按场切分天然保证"同一位球员的样本不跨折"。安慰剂 = 把测试场的 y 打乱后同一流程重算。

### 2.1 结果

| 模型 | 测试 R²（按场留出） | 安慰剂 |
|---|---|---|
| 线性（当帧上下文，14 特征） | 0.820（逐场 0.738–0.871） | −0.585 |
| **GBM（当帧上下文，14 特征）** | **0.886**（逐场 0.776–0.938） | **−0.914** |
| 线性 + 惯性（17 特征） | 0.986 | — |
| **GBM + 惯性（17 特征）** | **0.985** | −0.961 |

> **安慰剂为负 = 无泄漏的自检通过**。若安慰剂 > 0，说明流程有泄漏（第一版正是如此，
> 见 §1.3）。安慰剂的具体负值不是"泄漏量"——它约等于 −R²_真实。
>
> **协议差异（必须说明）**：线性跑**完整 20 折 LOOMO**（每次留 1 场）；
> GBM 因算力受限跑 **5 折**（每折留 4 场）——仍是按场分组、无同场泄漏，
> 只是测试集每折更大、方差更大。

### 2.2 上限的含义

**给定全部当帧上下文，横向位置的可预测性上限 = 0.886**（GBM；线性 0.820），
**未解释份额 11.4%**。加上惯性后上限升到 **0.985**（未解释份额 1.5%）。

⚠ 三条必须说清的口径：

1. **非线性/交互值 0.066**（0.820 → 0.886）。这是"线性模型捡不到、树能捡到"的部分，
   量级不大——说明**这一族因子与因变量的关系以线性为主**。
   ⚠ **但这个差值没有被完全归因**（审阅指出）：线性跑 **20 折 LOOMO**（每次留 1 场）、
   GBM 跑 **5 折**（每折留 4 场），**折数本身就会移动 R²**。
   本报告**没有做"线性在 5 折下"的对照**，故 0.066 里有多少是折数、多少是非线性，
   **未分离**。结论方向（非线性有小幅增益）可信，量级不可当精确值。
2. **11.4% 是"同时刻上下文"的未解释份额**。它**不是**"不可约的随机性"——
   加了惯性之后上限升到 0.985，说明这部分里**有一部分是可被位置自身的历史吸收的**。
   ⚠ **但不要把它归因成"慢漂移"**（本节的第一版正是这么写的，被审阅实测反证）：
   对**残差**做 slow/fast 分解（窗 120s），slow 只占 **20.3%**（400 人·队），
   不是"大部分"。`yPrev` 之所以能把 R² 抬到 0.985，主要吸收的是
   **§5 的 A 层（静态档位）+ 长时间尺度的位置连续性**，机制尚未分离（见 §6.4）。
3. **0.985 的解读要克制**：采样间隔只有 0.4s，位置在 0.4s 内几乎不变，
   故 `yPrev` 天然带走了绝大部分方差。**它不是"位置可完美预测"**，
   而是"**位置是慢变量**"——这本身正是 §7.2 建议的机制方向，
   但**不能用 0.985 当"引擎应当达到的精度"**（引擎的时间尺度与采样率都不同）。

> **对引擎的硬含义（这是本报告最重要的一条）**：
> 横向位置**不是**"掷骰子"——给定**局部相对结构**与**上一拍的自己**，
> 它在真实数据里 **98.5% 可预测**。所以：
> - **`formation_target(st, id)` 的问题不是"信息不够"，而是"没接这两个信号"**。
>   它只读球位（alone R² 0.029，§1.1）与静态模板。
> - 剩下那 1.5% 才是真正的"多稳态自由度"——**比 #101 预期的 20% 小一个数量级**。
> - 换句话说：**#89 不需要发明新信号，只需要用对已有的两个**
>   （局部相对结构 + 上一拍的自己）。

## 3. 那 82–89% 到底是什么：一个共同因子

**探针**：`probes-main/issue101-7-factor.mjs` → `out/101-7-factor.txt`

### 3.1 PCA：因子有 8 个自由度，但只有 1 个与 DV 有关

| | 解释因子方差 | **对 DV 的 alone R²** |
|---|---|---|
| PC1 | 27.2% | **0.728** |
| PC2–PC5 | 16.4 / 14.8 / 12.2 / 6.8% | 0.042 / 0.039 / 0.014 / 0.098 |
| PC6–PC14 | 合计 **22.7%** | 全部 ≤ 0.025 |

PC1 的载荷（前六）：`k3AnyY` 0.473、`k3MateY` 0.440、`k3OppY` 0.407、
`nearMateY` 0.402、`nearOppY` 0.387、`oppCy` 0.255；
球类（`ballY` 0.134、`ballDepth` 0.006）、纵向类（`ownX` 0.003）**几乎为零**。

### 3.2 这是什么

**PC1 = "周围所有人一起往哪偏"**——即 P38 §6 的 **swarm**（整队同进退）
在因子空间的投影。P38 曾用 `swarm` 判据（y 两两相关）在引擎侧抓这个现象，
当时它是个**现象指标**；这里它在真实数据里被识别为一个**独立的第一主成分**。

> **两条独立证据合流**：
> - P38 引擎侧：所有机制都挤在"latSd × swarm"同一条带里，改不动（§6 结论）。
> - 本报告真实侧：候选因子的一阶结构就是这一条带，PC1 就是它。
>
> **这意味着"换一个更好的标量信号"这条路在真实数据里也是死的**——
> 因为真实球员的横向结构本身就是"一个共同因子 + 一堆小修正"。

**但注意 §3.1 的第二列**：PC2 之后全部 ≤ 0.025。也就是说真实数据里
**除了这一个共同因子，没有第二个可命名的驱动**。这既解释了 §1.2 的"unique R² 全 ≈ 0"，
也是 #101 "仍然未知"的核心（§8）。

## 4. 局部结构 vs 绝对位置：是真信号吗

**探针**：`probes-main/issue101-6-null.mjs`（置换零假设）、`issue101-4-structure.mjs` → `out/101-6-null.txt`、`out/101-4-structure.txt`

### 4.1 置换零假设（决定性检验）

**零假设**：每帧每队把 10 人的 y **随机重排**（邻居选择仍用原始几何）。
若"局部结构"只是共享参考系造成的代数伪影，真实 R² 应落在零分布内。

| 特征 | **真实 R²** | 零分布均值 | 零分布 95 分位 | 真实 ÷ 零均值 | 判定 |
|---|---|---|---|---|---|
| `nearMateY` | **0.522** | 0.000 | 0.001 | **1051.6×** | ✅ 真信号 |
| `k3MateY` | **0.643** | 0.000 | 0.001 | **1325.8×** | ✅ 真信号 |

**解析对照**（⚠ 第一版这里写错了，审阅发现后已改）：

正确的推导：`Cov(y_j + A, F_i)` 中两项**精确相消**（A := `−mateY_i` 对 y_j 而言是常数），
故在"10 人 y 独立"的零假设下 **`Cov(DV_i, F_ij) ≡ 0`** —— 共享参考系对该回归
**不产生任何伪影**，R² 的真值是 **0**。

> 第一版把它写成了 `corr = 0.10, R² = 0.01`——那是把
> **`Cov(DV_i, DV_j) = −σ²/(n−1) = −0.111σ²`**（**两名球员的 DV 之间**的相关，且是**负**的）
> 连符号一起搬到了 (DV, 邻居因子) 这一对上。数值验证：`Cov/σ² = −0.0005`（真值 0）。

**零分布实测 ≈ 0.0005**，与真值 0 一致。**这使结论更强**：不是"0.52 远高于 0.01"，
而是"**0.52 在一个恒为 0 的量上**"——分离度是无穷，不是 52×。

> **判定**：局部结构是**真信号**，不是代数伪影。这与 P38 §1.2 的结论一致
> （"局部邻近，非盯人"），但**首次给出了零分布**——P38 当时只有
> "换成最近队友 R² 也 0.73"这一条定性证据。
>
> ⚠ **这个检验能支持什么、不能支持什么**（审阅指出，成立）：
> 它破坏的是"**同时刻队内 y 的配对**"——而"整队共享一个慢变量"（= §3 的 PC1/swarm）
> **也会**产生队内相关。故 `1050×` 证明的是"**y_i 与 y_j 的配对不是随机的**"，
> **不证明"驱动力来自最近邻"**。要证"局部"需要保留全局结构的对照
> （如只重排远邻、按距离分层置换）——**本报告没做**。
> §3（PC1 = swarm）与本节其实指向同一件事，两者尚未打通。
>
> **独立复核**（本报告完成后另写一套实现、只取 2 场 8,772 帧·队）：
> 真实 `k3MateY` R² = **0.649**（本报告 20 场为 0.643），零分布 8 次 = 0.0004–0.0008，
> 均值 0.0006，比值 **1081×**。与报告结论一致。

### 5.5 ⚠ 与 §2 的关系——两种聚合**回答不同问题**（第二轮审阅后重写）

`issue101-8-aggregation.mjs` 在同一份面板、同一因子集上把两者并列算出：

| 因子集 | pooled A / B / C（占总方差） | pooled 可解释 (A+B) | **MoP**（≡ B/(B+C)） |
|---|---|---|---|
| 7 个（§5 用） | 56.4 / 25.3 / 18.3% | 81.7% | **57.8%** |
| 14 个（§2 用） | 56.6 / 34.3 / 9.1% | 90.9% | **82.4%** |

**关键恒等式**（把两节打通的那条）：

> 逐人回归的**截距就是该人的均值**，而它已从 SST 里被扣掉，
> 故 **`MoP R² ≡ B/(B+C)`**。
> 自检：7 因子 B/(B+C) = 25.3/43.6 = **58.0%** ↔ 实测 MoP **57.8%**；
> 14 因子 34.3/43.4 = **79.0%** ↔ 实测 **82.4%**（差异来自成列删除与加权）。

**所以两个口径的分工是**：

- `pooled` 把**个人固定效应（A）**算进"可解释"，给出 A/B/C 三层。
- `MoP` 的截距吸收了 A，只回答"**扣掉个人档位后，情境能解释多少**"。
- 因此**"聚合差"不是一个有意义的量**——第一版把它相减，第二轮审阅的修复建议
  要求"改成逐人 MoP"，两者都只对了一半。现在以探针 8 的**落盘输出**为准。

**§2 的三个数字（同 14 因子集，不可混引）**：

| 协议 | R² |
|---|---|
| 线性，**样本内** MoP（上表 82.4%） | 82.4% |
| 线性，**LOOMO 出样**（§2.1 的 0.820） | 82.0% |
| GBM，5 折出样（§2.2 的 0.886） | 88.6% |

出样惩罚（82.4 → 82.0，−0.4pp）与非线性增益（82.0 → 88.6，+6.6pp）——
后者正是 §2.2 注 1 说的"0.066 里折数与非线性未分离"。

> ⚠ §5 的 A/B/C **不能**直接与 P38 #90 §2.1 的"静息档位 32.1%"对账——
> #90 用**总方差为基**、且是 pooled。§5.3 的换算（32.1/60.5 = 53.1% ↔ 56.4%）
> **只在 pooled 口径内部成立**。

### 5.6 对引擎的含义

- **静态档位 56.4%**：引擎的静态模板**不是错的方向**，它只是"只做了这 56%"。
- **情境响应 25.3%**：把球/对手/邻居全给足（**线性**），当帧情境只解释这么多。
  ⚠ 但 §2 证明**非线性还能再拿 ~7 个点**——所以 25.3% **不是**天花板，
  0.886 才是（§2.2）。**不要把 25.3% 当"响应路线的极限"引用。**
- **个体残差**：线性之后 18.3%（**若纳入邻居位置因子则降到 10.9%**，§5.1b），
  GBM 之后 11.4%——**这才是"情境之外"的真实自由度**。
- **结论**：职责与响应都要建；① 静态档位已经做对（引擎 99% 在这一层），
  ② 响应层（B）**引擎完全没有**，③ 残差层（C）比 #101 预期的小得多（11–18%，非 20%）。
  ⚠ **不要把 C 的内部构成说成"大部分是慢漂移"**（第一版如此，被 §6.1 的残差分解反证：
  残差的 slow 占比只有 20.3%）。

### 6.4 真正未知的三件事

2. **个体残差（11.4%，GBM 之后）的来源**：是"同一球员的随机选择"、"未被观测的情境"，

3. **惯性的机制**：`yPrev` 解释 0.933，但这个数字**同时包含**"位置本身慢变"与

## 7. 对引擎设计的含义（承接 #89）

> 本节是经验事实的推论，不是机制设计（设计归 #89）。

### 7.1 被证伪的方向

| 方向 | 证据 |
|---|---|
| **换一个更聪明的标量信号**（球、对手、球门） | §3：候选因子的 PC1 就是"周围人一起偏"，且没有第二个可命名的驱动 |

### 7.2 被数据支持的方向

1. **强惯性**（§1.1 `yPrev` 0.933）：横向目标应当是**上一步位置的函数**（低通/阻尼），
   而不是每拍从零算一个点。这是 #101 候选清单里"时间维度"的直接命中，
   且**P38 从未试过**（P38 试的全是"当帧信号"，没有一项用 `yPrev`）。
2. **局部相对结构**（§4.2 相对 0.760 vs 绝对 0.101）：横向目标应当由
   **与队友/对手的相对关系**定义，而不是绝对坐标。
   这正是 `mechanism-exploration.md` §6 与 `findings-final.md` §7.4 给出的建议
   （"把横向目标从'算出来的点'改成'由局部相互作用定义的关系'"）——
   **本报告首次给出了支持它的零分布证据（1050×）**。
3. **多稳态自由度**（§2.2：GBM 之后仍剩 11.4%）：机制应当允许
   "同一情境 → 多个合理位置"。⚠ 但**量级比 #101 预期的小**（11% 而非 20%）。
   其内部构成**尚未分离**（§6.4：对残差的 slow/fast 分解 slow 只占 20.3%）。
   **优先级应低于 ①（惯性）与 ②（局部结构）**——探针 1 显示这两条对应
   `yPrev` 0.933 与相对结构 0.760，量级远超剩下的残差。

### 7.3 给验收判据的含义（承接 #91）

- **`yPrev`（0.933）给出了一个新的判据维度**：真实球员的横向位置**强自相关**。
  引擎基线是"一整场不变的常数"（P38 #90 §2.1：静息档位 99.4%），
  自相关同样接近 1——**这条判据区分不了**，除非配合 `latSd`。
- **§5.1 的三层分解可以当靶子**。换算到本报告基数（DEV = 扣掉队伍平移后），
  真实是 **A 56 / B 25 / C 18**（现版因子集；**若含邻居位置因子则是 53/36/11**，§5.1b）；
  引擎由 P38 #90 §2.1（总方差为基：队伍层 0.2 / 静息档位 99.4 / 个体游走 0.5）
  换算到 DEV 基数 = **A 99.5 / B 0 / C 0.5**。
  → **A 已经对了，B/C 是零**。新判据可以是"**B+C 的占比 ≥ 40%**"，
  它**不会**被"只重排静态模板"的方案买到（那个方案只会换一个 A）。
  ⚠ 注意：引擎的 **B 层不能只靠现状的当帧信号（球位）**——§3 已证真实侧的当帧情境
  也才 25.3%；B 层真正的来源是**局部结构**（§4.2：相对 0.760 vs 绝对 0.101）。

## 附：本报告**没有**做的事（边界声明）

1. **没有碰引擎**（#101 明确"纯数据问题，不需要改引擎"）。所有数字都是真实数据侧。
2. **没有做跨场球员身份**（数据不支持，见 §5.0）。
3. **没有测朝向**（数据不支持，见 §6.2）。
4. **没有做采样率分解**对 `yPrev` 的影响（见 §6.4-3）。
5. **没有区分 PC1 里"跟队友"与"跟对手"**（见 §6.4-1）。
6. **GBM 是算力受限的近似**（深 3、60 棵、每场 6000 行下采样、5 折而非 20 折）
   → **低估**上限。故 0.886 是**下界**，真实上限只会更高。
7. **没有把"局部性"与"共同因子"分开**（§4.1 的检验语义）。
8. **没有做聚合口径的并列表**（§5.5）——§5 与 §2 各报各的，读者若要跨越两节
   自行换算，需注意 pooled vs mean-of-per-person。
9. **`nearAnyDist`（unique R² 0.033 排第一）未做对照**：它的 β = 0.002（~2mm/m），
   更像共线性下的方差再分配而非机制信号，**没有跑"打乱距离字段"的安慰剂**。
