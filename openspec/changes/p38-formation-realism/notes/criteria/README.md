# P38 #91：验收判据（成组否决 + 变异自证）

## 这是什么

**判断一次队形改动是「真修复」还是「拟合数字」的可执行判据组。**

动机：P38 探索中做了 6 个改动，**每一个都能让部分指标变好看**，
其中 exp4b（等间距重排）在**四条指标上全部达标**——却是纯 hack。
单条判据会被"买"（exp1 的纵深被挡但 swarm/midBack 达标），所以判据必须**成组否决**。

## 判据组（任一条不达标 → 整体不通过）

| 组 | 判据 | 真实中心值 | 容差 | 挡住谁 |
|---|---|---|---|---|
| 纵向 | 纵深 hd | 25.89 | ±2.5 | exp1/exp4b 之外的全部 |
| 纵向 | 紧凑度 spread | 15.21 | ±1.8 | 除 exp4b/exp3 外 |
| 纵向 | 重心间距 gap | 8.34 | ±1.8 | 除 exp4b 外全部 |
| 横向 | 横向位移 sd latSd | 10.52 | ±3.5 | **exp4b（唯一能挡它的之一）** |
| 整体性 | y 两两相关 swarm | 0.671 | ±0.22 | 基线/exp3/exp4b |
| 结构 | 断层幅度 fault | 4.95 | ±2.5 | 全部 6 个变体 |
| 结构 | 各线均衡 midBack | 1.06 | ±0.22 | exp3/exp5/exp7 |

**变异自证结果**：真实值 ✅ 通过；6 个已知变体**全部**被挡。

## 关键反例（为什么必须成组）

- **exp4b（等间距重排）**：纵深 26.3 ✅ / 紧凑 15.5 ✅ / 重心距 7.9 ✅ / 各线均衡 1.04 ✅
  —— **四条达标**。只被 **latSd 0.21**（横向，真实 10.5）、**swarm −0.04**、**fault —** 挡住。
- **exp1（模板压缩）**：纵深 21.2 ❌ 被挡，但 swarm 0.61 ✅、midBack 1.16 ✅ ——
  只看后两条会误判成功。**指标之间会互相买账。**

## 怎么用

```bash
# 1. 全量评测（会反复改引擎源码与 wasm，跑完自动还原）
node drive-criteria.mjs

# 2. 只标定阈值 + 变异自证（读 table.json）
node calibrate.mjs
```
