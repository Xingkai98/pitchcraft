## 2. 「跳过外推」是否与球位置相关（选择性偏倚的直接检验）

按球深度（离本方门线，7 桶）统计**真检测率**（= 1 − 外推率），逐队逐桶。若与球位置无关，
各行应接近常数；若两端低 → 跳过外推会系统性削掉队形两端（= 横向分布的选择性偏倚）。

两端 vs 中间：最深桶 52.5% / 最浅桶 39.6% vs 中间桶均值 66.6% → 差 20.6 个百分点。
（方向与 P38 `findings-final.md` §1 的 U 形一致：真检测率沿深度两端低。）

**对账结论**：
`metricadata 真检测` 行 25.57 / 32.94 / 40.41（距中轴 −8.43 / −1.06 / +6.41，档心跨度 14.84）
对照 `real-formation-laws.md` §6.3 的 Metrica 25.8 / 33.4 / 40.2（−8.23 / −0.62 / +6.23，跨度 14.5）；
`skillcorner 真检测` 行 23.74 / 33.77 / 44.41（−10.26 / −0.23 / +10.41，跨度 20.66）
对照同表的 23.9 / 33.7 / 44.2（−10.13 / −0.27 / +10.23，跨度 20.4）。**两条路径逐项吻合**
→ 本套装载器与那份报告口径可比，差仅来自球帧过滤（本表不过滤 `ballFill`）与四舍五入。

**口径差本身**（同一批帧，只换外推点采信与否）：SkillCorner 宽度 29.34/27.69/28.86
（全点）vs 26.96/25.33/27.67（真检测），**全点宽 2.3–2.4m**；重心档心跨度 19.04 vs 20.66。
即"跳过外推"同时**窄化**队形与**夸大**重心跟随幅度——两者都不是真实观测的差异，
而是缺失模式与球位置相关的产物。本套探针主口径取全点（恒 10 人面板）。

## 3b. ⚠ 半场换边：y 轴需要跟着 x 一起翻（本套探针修掉的口径 bug）

半场换边 = 绕场地中心 180° 旋转。转换器翻了 x 但没翻 y → 跨半场的个体统计被污染。
修正 = team-relative 横向 `yCanon`（见 `q90-common.mjs` 的 `lateralFlip`）；
Metrica 转换产物不含 `period`，半场边界由**数据**定（取使**逐人方差均值**最小的 t0）。

   Metrica 场次           检测出的半场边界 t0      源 flipX(逐半场)        逐人方差均值 未修正         修正后        降幅
─────────────  ────────────────────  ────────────────  ────────────────  ──────────  ────────
            1       2850s (47.5min)      [false,true]             219.3       161.3     26.5%
            2       2715s (45.3min)      [true,false]             206.1       164.9     20.0%

**为什么用「逐人方差的均值」做判据，而不是池化方差**：池化会把 20 个人的左右差异
互相抵消，目标函数对 t0 几乎不敏感（实测曲线平到 471.6 vs 478，会选到区间端点）；
逐人方差均值对同一现象敏感得多，曲线是干净的碗形、谷底明确。

## 4. 本套探针的口径（写进 real-lateral-laws.md 的那份）

1. **y 分量一律用 PITCH_WIDTH_M(68)**；实测 8 场球场宽恒 68（04-width-channels.mjs 已核）。
2. **x 客队镜像**（→ 离本方门线距离）；**y 做 team-relative 朝向归一**（`yCanon`，
   半场换边时跟着 x 一起翻，见 §3b）——**不是**"不镜像"（那是修正前的错误口径）。
3. **球员面板恒 10 人/帧/队**（全点口径，含 SkillCorner 外推点）。理由见 §1/§2；
   凡结论与真检测口径差 ≥0.3m 或 ≥3pp 的，在正文处单独标注。
4. **相位**：SkillCorner 用源数据 `possession.group` 真值（侧信道 `*-phase.json`，
   由 `buildSkillcornerPhase()` 从原始 jsonl 重建并**逐帧断言 t 与转换产物相等**）；
   Metrica 无此字段，退回最近球员代理（`corpus.poss`）。两者**分列，不混池**。
5. **球相关量只用球的原始观测帧**（SkillCorner: `ball_data.is_detected === true`，
   n≈18205/22122 等；Metrica 无外推概念，全部可用）。
6. **槽位 ≠ 位置身份**：Metrica 与引擎用"按整场平均深度排的固定槽位"；
   SkillCorner 另有真实 `position_group`（`roles.mjs`），个体分析优先用它。
