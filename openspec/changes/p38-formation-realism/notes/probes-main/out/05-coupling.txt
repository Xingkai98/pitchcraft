## Q5b. 逐人回归 `y ~ x`：前进 1m 时横向动多少？

逐「人·场」做单变量回归（x 已镜像成"离本方门线距离"，y 已做朝向归一）。
斜率 0 = **沿边线/沿直线直上**（纵向走、横向不动）；
斜率显著非 0 = 纵向移动伴随横向漂移（内切/外扩）。

## Q5c. 横向位置与球侧的耦合：球员偏离重心的方向是否指向球？

对每个「人·场」，算 `corr(y − cy, ballY − cy)`（他偏离重心的方向 vs 球偏离重心的方向）。
+1 = 永远站在球的同侧（"球侧倾斜"）；0 = 与球侧无关（固定职责）；
−1 = 永远站反侧。逐人算后再跨人平均。

         数据集      人·场 n   corr(y−cy, ballY−cy) 均值        sd       q10       q90
────────────  ─────────  ────────────────────────  ────────  ────────  ────────
     metrica         40                     0.007     0.106    -0.120     0.145
 skillcorner        120                     0.003     0.158    -0.179     0.227
      engine         20                     0.005     0.089    -0.128     0.102

⚠ **这个简单相关被共享项污染了**：`y−cy` 与 `ballY−cy` 都含 `−cy`，
而 `Var(cy)` 很大（Q1），这一项给相关系数加了**正的**贡献。故简单相关 ≈0 意味着
**去掉共享项后真实关系是负的或更接近 0**。表格下方给**偏相关**（把 cy 从两边都回归掉）。

**读法**：偏相关就是"这个人的横向站位有多少由球侧决定"的量化（扣掉全队平移）。
≈0.5 → "一半跟球、一半守区"（球侧倾斜 + 职责区混合）；接近 1 → 纯球侧倾斜（无职责）；

## Q5d. 纵向推进时横向实际动多少（用 **速度** 而非位移增量）

取每个「人·场」序列的**相邻两条记录**，算横向速度 `|Δy| / Δt`（m/s）。
只保留 `Δt ≤ 0.4s` 的对（SkillCorner 的 `ballDet` 过滤会造成成片缺帧，
长间隔的对会把"慢漂移"与"抖动"混在一起——不做 Δt 归一的话数字会随过滤策略变 45%）。
按纵向速度分桶：前跑 `Δx/Δt > 1.25 m/s`、静止 `|Δx|/Δt < 0.25 m/s`、后退 `Δx/Δt < −1.25`。
同时剔除球位剧变对（`|Δ球y|/Δt > 2.5 m/s`），避免把"球转移导致全队横移"算进来。

         数据集    Δt 中位(s)      n(前跑)    |vy| 前跑      n(静止)    |vy| 静止    |vy| 后退      前跑/静止
────────────  ──────────  ─────────  ─────────  ─────────  ─────────  ─────────  ─────────
     metrica        0.20     127310      1.060     165784      0.527      1.090       2.01
 skillcorner        0.20     241250      1.228     156775      0.780      1.262       1.57
      engine        0.20      21828      0.277     451411      0.003      0.352      81.43
（单位 m/s。所有量都按真实 Δt 归一。）

**读法**：`|vy| 前跑` vs `|vy| 静止` 的比值 → **纵向跑动时横向并不「额外」动**（比值 ≈1）
还是"跑起来才横move"（比值 >1）。**绝对值才是关键**：
真实即使"纵向不动"的帧，横向也在以 0.5–0.9 m/s 移动；引擎 0.00–0.01 m/s。
