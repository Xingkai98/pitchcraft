## 6.3 解析底噪（对照）

若 10 人的 y **互相独立**（方差 σ²），共享参考系造成的伪影可解析求出——**它是 0**：

```
DV_i  = y_i − mateY_i        （mateY_i = 其余 9 人均值）
F_ij  = y_j − mateY_i
Cov(DV_i, F_ij) = Cov(y_i, F_ij) − Cov(mateY_i, F_ij)
  Cov(y_i, F_ij)    = 0 − 0 = 0          （y_i ⊥ y_j；y_i 不在 mateY_i 里）
  Cov(mateY_i, F_ij) = σ²/(n−1) − σ²/(n−1) = 0
  ⟹ 两项均为 0
  ⟹ 独立零假设下 Cov(DV_i, F_ij) ≡ 0,  即该回归的 R² 真值 = 0
```

> ⚠ **第一版这里写错过**（第二轮审阅发现）：它写 `Cov = 0.111σ²`、`corr = 0.10, R² = 0.01`。
> 那是把 **`Cov(DV_i, DV_j) = −Var(DV)/(n−1) ≈ −0.1235σ²`**（**两名球员的 DV 之间**，且是**负**的）
> 连符号一起搬到了 (DV, 邻居因子) 这一对上。数值验证：`Cov/σ² = −0.0005`（真值 0）。

> **结论因此更强**：真实 R²（0.52 / 0.64）落在一个**恒为 0** 的量上——
> 分离度是无穷，不是"52 倍"。零分布实测 ≈0.0005 与真值 0 一致。
