## Q2a. 个体 y 的方差分解：全队平移 / 位置职责 / 个体游走

在**每个「队·场」**内对「全体非门将 × 全部时刻」池化（不是逐人算再平均——逐人算时
两项不正交，会出荒谬值）：

```
Var_pooled(y)  =  队伍层 IT  +  个体层 DEV
  IT  = E_t[(cy_t − ȳ)²]              ← 全队随球的整体横移（逐帧共享量）
  DEV = E_{i,t}[(y_it − cy_t)²]       ← 此刻相对全队重心在哪
DEV            =  静息档位  +  个体游走
  静息档位 = E_i[(ȳ_i − ȳ)²]          ← 位置/职责的固定横向偏移（整场不变）
  个体游走 = 其余                      ← 职责附近的实际跑动
```

代数上交叉项恒为 0（每帧 Σ_i (y_it − cy_t) = 0）。三列 = 各层占 Var_pooled(y) 的百分比。

         数据集      人·场 n         队伍层(全队平移)         静息档位(职责偏移)        个体游走  Var(y) m²
────────────  ─────────  ────────────────  ─────────────────  ──────────  ─────────
     metrica          4             28.5%              28.8%       42.7%      230.3
 skillcorner         12             37.1%              34.0%       28.9%      250.4
      engine          4              0.2%              99.4%        0.5%      149.8

**读法**：真实球员的横向方差在三个来源上**大体均分**——
队伍整体平移 **28–37%**、位置/职责的固定档位 **29–34%**、个体在职责附近的游走 **29–43%**。
即：横向移动**既**是全队平移、**也**是位置分工、**也**是逐帧的跑动，三者都不可省。

⚠ **本表在修正半场朝向前是错的**：未修正时"个体游走"被虚高到 52–65%、"静息档位"被压到 4%。
原因是半场换边把每名球员的 y 搬到球场另一侧，那部分位移被记成了他的"跑动"。
修正（`yCanon`，见 `00-caliber.txt` §3b）后才三足鼎立。**这是本票据对既有结论的实质修正。**

引擎侧仍是另一个极端：**静息档位 99.4%**、队伍层 0.2%、个体游走 0.5%——
引擎球员的 y 几乎是一整场不变的常数（只有模板 base.y 的固定档位）。
**这不等于"引擎没有位置分工"**：99.4% 说明它的分工是**绝对静态**的；
真实的分工只占约 1/3，另 2/3 是动态的。差别在"动态"而非"有没有分区"。

## Q2b. 因子解释力排序（逐「人·场」回归，跨人取均值）

**两层各用一套不泄漏的构造**（这是本探针最容易出错的地方）：

- 队伍层（DV = 队重心 cy）：观测单位是**帧**（每队·场一批 (cy, ballY, oppY, phase, meanX)），
  自变量**不含任何队友均值**——`mateY` 与 cy 在代数上几乎重合（cy = (9·mateY+y_i)/10），
  放进去会得到 R²≈99% 的退化模型（首版实测）。
- 个体层（DV = y_i − mateY，mateY 留一）：观测单位是**人·帧**，自变量不含队友项。

### 队伍层：DV = 本队重心 cy（米）

⚠ **先说清这张表能读什么**：`ballY` 与 `oppY` 高度共线（r = 0.83），
而"两队横向重心近乎锁定"是**数据结构本身**——实测两队的 cy 在**绝对**坐标下
相关系数 **−0.87 ~ −0.98**（一队向左、另一队必向右），转到同朝向后接近 +1。
故 `oppY` 在排序里领先，主要说明"两队在横向上一体移动"，
**不代表它是一条独立的因果通道**（共线下"谁排第一"由最后加入的顺序决定）。

## Q2c. 自变量之间的相关（SkillCorner，全员逐帧池化）

**为什么必须看**：nearOppY（最近对手的 y）与球位高度共线——
"最近对手"通常就是贴着球的那个防守人。若不看相关矩阵，会把"球位"的效应误记到"对手"头上。

              ballY    mateY     oppY   nearOppY     ownX    phase
──────────  ───────  ───────  ───────  ─────────  ───────  ───────
     ballY     1.00     0.82     0.83       0.58     0.01    -0.02
     mateY     0.82     1.00     0.96       0.62     0.01    -0.01
      oppY     0.83     0.96     1.00       0.69     0.01    -0.01
  nearOppY     0.58     0.62     0.69       1.00     0.03    -0.01
      ownX     0.01     0.01     0.01       0.03     1.00     0.17
     phase    -0.02    -0.01    -0.01      -0.01     0.17     1.00

池化（n=2089720 人次）：

  `nearOppY ~ ballY`：斜率 0.380，R² 0.339 → 最近对手的横向位置有 33.9% 由球位解释。
  把球位从两边都剥掉后，`y 残差 ~ nearOppY 残差`：斜率 0.961，R² 0.616 → **"最近对手"在剥掉球位后仍解释 61.6% 的方差**。

### 安慰剂对照：把"最近对手"换成"第 k 近对手"

若相关随 k（第几近）**单调下降**，则"相关性"至少部分来自**空间邻近的距离衰减**，
而不是"每人盯一个固定对手"的职责。

        第几近的对手        n 人次        斜率       R²(对手→我)       R²(我→对手)
──────────────  ──────────  ────────  ─────────────  ─────────────
           1 近     2089720     0.535          0.277          0.277
           3 近     2089720     0.227          0.062          0.062
           5 近     2089720     0.084          0.009          0.009
      10 近(最远)     2089720    -0.427          0.347          0.347

**读法**：k=1/3/5 的斜率与 R² **单调下降**（0.535/0.277 → 0.227/0.062 → 0.084/0.009）。
→ 相关性随距离衰减，与"**空间邻近（贴身）**"一致，**不足以**单独证明"每人盯一个固定对手"。

`10 近(最远)` 一行斜率 **−0.427**、R² 反而高（0.347）：这不是"更强的盯人"，
而是**镜像**——最远的对手必然在你反侧，于是在球位控制下两者近似线性镜像。
它的 R² 高只说明"最远的人与我最反相关"，是几何必然，不是战术信息。

**结论（与 Q3e 合并读）**：个体横向位置的最大单一解释项是"最近对手的 y"（unique 28–35%），
但安慰剂显示它主要由距离衰减驱动。结合 Q3e（真实球员左右占比约 70:30）、Q5b（纵向几乎不耦合），
**最简约的机制解释是"球侧倾斜 + 弱职责档位"，而不是"人盯人"或"固定通道"**。
