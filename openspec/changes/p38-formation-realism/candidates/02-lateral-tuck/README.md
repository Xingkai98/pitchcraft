# 候选 02：球侧过载 + 远端内收

## 改了什么

`exp7-ballside-tuck.patch`：`formation_target` 的横向（y）项从"全队同一个球位系数"
改成**按球员相对球侧的远近分化**——远侧球员向内收（tuck in）、近侧保持宽度。

```rust
let farness = if same_side { 0.0 } else { 1.0 };   // 我离球侧多远
let tuck = BALL_SIDE_OVERLOAD * farness;           // 同侧 0 .. 对侧 0.30
let ty = base.1 + ball_side * tuck;
```

## 为什么

横向是本轮发现的**最大单项缺口**：真实球员人均横向位移 sd **12.5m**，引擎只有 **3.4–5.1m**。
而真实球队的特征是"向球侧倾斜，但**各人幅度不同**"。之前的实验 5（全队同一个球位系数）
产生了"整队像一群鱼横移"的假象（y 两两相关 0.629 → **0.950**）。

本候选试图用"远端内收"这个**有足球含义**的机制来制造个体差异。

## 实测结果

| 判据 | 真实 | 基线 | 本候选 |
|---|---|---|---|
| y 两两相关（swarm，越低越好） | **0.606** | 0.629 | **0.727** ⚠️ |
| 横向位移 sd | **10.04m** | 0.53m | **1.31m** ❌ |
| 宽度 | 39.58m | 40.85 | 38.65 |

## 我的判断

⚠️ **方向对，力度远远不够**：
- ✅ swarm 从 exp5 的 0.950 降到 0.727（比"一群鱼"好）
- ❌ 横向位移只有 1.31m（真实 10.04）——比 exp5 的 5.30m 还差
- 轨迹图（`notes/visual/traj-exp7.png`）显示出现了斜向/弧线（不再是纯水平线），
  但**方向散乱、缺少真实的连贯跑动带**

**原因**：`farness` 是**二值**的（同侧/对侧），每人的 tuck 只有两个取值。
真正的差异应来自**连续量**（离球侧多远、职责、是否在跑动中）。

**没做但可以试**：把 farness 改成连续的 |y_me − y_ball| 归一化；或让职责（边卫/中场/前锋）
有不同系数。
