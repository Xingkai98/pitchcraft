## D2 为什么是**一条直线**而不是 8 节点查表

对 D1 的 8 个观测分箱中位做最小二乘 ⇒ `斜率 0.2440 / 截距 −0.4632`；`d < 10.1 m` 时直线低于地板，
由 `GK_COME_OUT_FLOOR_M = 2.0` 托住（真实没有「球距门线 → 0」的观测）。

**节点表对 P4 非必要**：判据镜在同一批观测分箱中位数上独立复算，直线在头条两项上**比节点表更贴真实**
（主 12.008 vs 12.363；客 12.381 vs 12.004 — 节点表客侧反而偏 −0.35），四项判据里三项无差别。
**残差大 ≠ 落地差**：8 节点上的最大残差 ~1.4 m（d=77.5 处）**不转化为 P4 差异**。
⇒ 少 6 个常量、少一段插值代码。**「纵向必须非线性」这条主张撤回。**

## D3 改什么、不改什么（边界）

- **改**：门将目标表达式（纵向直线 + 横向 `GK_TRACK_Y`）；`formation_target` 的一句陈旧注释。
- **不改**：`GK_SPEED_MS` / `DEAD_ZONE_METERS` / action 名 `keeper_return` / 同队间距分离 /
  任何其它常量 / 任何 `pub const` / 任何判据（`DUR` / `TICK_SECONDS` / seed 集 / detector / 带值）。
- **`keeper_return` 这个名字保留**：改名会牵动既有测试的断言面，**语义已变为「门将移动」**，
  在常量注释里写死这一点。

   300 seed（门自身口径），不是判据镜的 5 seed 子集（那是 7.15 m / 2.20×）。
   M1 在同口径上是 8.84 m / **1.78×** ⇒ **直线比节点表薄**，进账。
> ⚠️ **【树】标签（2026-10-17 审阅修复补）**：本 D4 的 2/3 两条是 **M1b-only 树**
> （`/tmp/m1b-clean` = base + M1b patch）的**设计期**读数。**落地树（M5 + M1b）**的同口径读数是
> `<2.2 m` = **79/29/19**、`<5 m` 比值 = **40.5×/30.0×/23.0×**（独立审阅用同一支探针三树各跑一遍：
> base 行与 M1b-only 行逐位复现旧记录 ⇒ 树归属坐实）。**树不同则数不同、机制画像也不同**，
> 引用时须带树标签（本仓教训：「效应量不跨口径迁移」）。规格正文（delta 的「代价」条）**只用落地树读数**。

2. **门将↔队友 `<5 m` 频次 29×/32×/28× 基线**（M1b-only 树；M1 是 24×/25×/19×）。
3. **`<2.2 m`（分离触发线）对数 2/12/61**（M1b-only 树；基线 0/1/0，M1 0/0/1）——**未跨分离线**
   （`spacing-sweep` 仍 0 findings），但「门将是一具普通身体，`commit_beat_positions` 会把跌破阈值的
   同队对推开，被推开的队友又在下游改变事件流」这条因果**是解释，不是已证因果**（未做消融）。
   观测事实：M1b 相对基线有 **2/5** 的 seed 在**门球之前**就出现真实分歧（M1 是 0/5）。
   ⚠️ **「未跨分离线」这条结论的口径**：上面那三个数是 **0.2 s 插值帧**口径，两拍线性插值会切角、
   造出「两人交叉」的**伪影对**；**tick 口径**（逐拍 22 人）下三 seed 最小同队间距恰 = **2.200 m**、
   `<2.14 m` 与 `<2.0 m` 全为 0 ⇒ 分离线确实未被越过，但**必须用 tick 口径说**。
4. **旧尺子上的「效应大 4 倍」已失效**：`M1b − 基线` 在 `禁区内进球占比` 上
   `slab −0.0176（t=−2.33）` → `rect −0.0115（t=−1.75, n.s.）` → **叠 M5 后 +0.0000（t=+0.01）**。
   **不得**把旧口径的 Δ 搬到新口径（本仓既有教训：效应量不跨口径迁移）。
