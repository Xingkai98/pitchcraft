# Proposal: 出界重开体系——角球 + 界外球 + 头球（out-of-play-restarts）

## Why

P6 首批完成了"门球 + 进球回中圈"，但球出界后的完整重开体系还不存在：传球/射门出界只有门球一种去向，没有角球、界外球；禁区内的争抢（尤其角球后的头球解围/头球射门）没有建模。

用户 batch-grill 确认（2026-08-08）：**批次1 = 出界重开**（出界判定 + 角球 + 界外球 + 头球）；批次2 = 犯规 + 任意球 + 点球。

## What Changes

- **出界判定**：传球出边线 → 界外球（对方掷）；传球出底线 → 门球；射门被扑出底线 → 角球（进攻方）。不做"最后触碰方追踪"（批次2/后续），传球出底线一律门球（简化）。
- **角球机制**：
  - 角球从角旗区开出（长角球）→ pass 高亮 + 高度感 → 落点禁区附近 → 松散球。
  - **禁区争抢**：落点最近攻/防球员争，攻方得球概率稍高（55/45）。
  - 攻方抢到 → **头球射门**（shot 高亮，~10% 进球）/ 摆渡 / 拿球组织。
  - 防方抢到 → **头球解围**（顶出禁区 → 松散球重新争）/ 解围出底线（再角球）/ 解围出边线（界外球）。
  - 头球**复用 shot/pass 高亮**，不新增事件类型。
- **界外球机制**：从边线掷向附近队友（pass 高亮，短传无高度），对方掷（传球出边线 → 对方）。

## Capabilities

### New Capabilities

无（复用高亮/松散球/DeadBall 机制，新增出界判定 + 角球/界外球类型 + 头球演绎）。

### Modified Capabilities

- `match-engine`：出界判定（传球落点出界 → 重开类型）；角球（角旗区开球 + 禁区争抢 + 头球）；界外球（边线掷球）；DeadBall 支持角球/界外球类型。
- `event-stream-protocol`：无结构变化（复用 pass/shot 高亮 + beat.ball loose）；可能加 detail 表达头球/出界。
- `pitch-viewer`：角球发球高亮 + 禁区争抢 + 头球演绎（头球射门/解围）；界外球掷球；出界视觉。

## Impact

- 引擎：DeadBall 状态机扩展（角球/界外球）+ 出界判定 + 头球争抢决策 + 头球高亮产出。
- viewer：角球/界外球演绎 + 头球演绎（复用 shot/pass）+ 出界视觉。
- 测试：引擎（出界判定/角球流程/头球解围/头球射门/界外球）+ viewer（角球/头球/界外球）。

## 关联票据（wayfinder）

- `10` 定位球 + 犯规规则层 → P6 批次1 落地出界重开（角球/界外球/头球）；批次2 做犯规/任意球/点球。
