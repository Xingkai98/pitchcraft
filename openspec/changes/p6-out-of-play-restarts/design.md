# Design: 出界重开体系——角球 + 界外球 + 头球（out-of-play-restarts）

## Context

P6 首批完成门球 + 进球回中圈。用户 batch-grill 确认批次1 = 出界重开：出界判定 + 角球 + 界外球 + 头球。批次2 = 犯规 + 任意球 + 点球。

本 change 复用已建成的 DeadBall 状态机（门球链路）+ 高亮机制（pass/shot）+ 松散球双方可争，不新增架构。

## Goals / Non-Goals

**Goals:**
- 出界判定：传球出边线 → 界外球（对方）；传球出底线 → 门球；射门被扑出底线 → 角球（进攻方）。
- 角球：角旗区长角球 → 禁区 → 争抢 → 头球（解围/射门/摆渡，可进球）。
- 界外球：边线掷向附近队友（对方掷）。
- 头球复用 shot/pass 高亮，不新增事件类型。

**Non-Goals（批次2/后续）:**
- 犯规判定 + 任意球 + 点球（批次2）。
- 最后触碰方追踪（传球出底线归属）——简化一律门球。
- 越位。
- 防守人墙/任意球排墙。

## Decisions

### D1: 出界来源与重开类型（Q2 grill 确认）

| 出界情形 | 触发 | 重开 |
|---------|------|------|
| 射门打偏 → 底线 | result=off_target | 门球（已有） |
| 射门被扑出 → 底线 | result=saved + 扑出 + 球到门线外 | 角球（进攻方） |
| 传球出边线 | pass 落点出边线（y<0 或 y>1） | 界外球（对方） |
| 传球出底线 | pass 落点出底线（x<0 或 x>1） | 门球（简化，不做触碰归属） |

### D2: 出界判定实现（批次1 简化）

- 传球：低概率（~3-5%）落点出界——落点 x/y 超出 [0,1] 一段（≤0.05 归一化，球飞到边界外一点）。
- 事件坐标：出界落点**仍钳制到 [0,1]**（球停在边线/底线），事件带 `detail` 表达出界类型（`"out_sideline"` / `"out_goal_line"`）。
- 引擎据 detail 触发对应重开；viewer 球飞向边界（钳制到边缘）。

**为什么**：协议坐标 [0,1] 校验不破坏；出界视觉 = 球到边界；简化不追踪触碰归属。

### D3: 角球机制（Q3 grill 确认：完整版）

角球从角旗区（进攻方右侧/左侧角）开出：
1. **长角球发球**：pass 高亮，起点=角旗区（x=0/1, y=0/1），落点=禁区附近（x 贴近门线、y 球门范围），带高度感（h）。
2. **落点松散球**：落点无人持球 → 松散球（双方可争）。
3. **禁区争抢**：落点最近攻/防球员争，**攻方得球概率 55/45**（C2A）。
4. 攻方抢到（C1A 复用 shot/pass）：
   - **头球射门**（~55%）→ shot 高亮（起点=争抢点，方向=球门），进球率 ~10%（C3A）；miss → 门球。
   - **头球摆渡**（~30%）→ pass 高亮给队友 → 正常组织。
   - **拿球组织**（~15%）→ main 恢复（持球者）。
5. 防方抢到：
   - **头球解围**（~70%）→ pass 高亮顶出禁区 → 落点松散球重新争。
   - **解围出底线**（~20%）→ 再角球（进攻方）。
   - **解围出边线**（~10%）→ 界外球（进攻方）。

**为什么**：完整呈现"角球 → 争抢 → 头球解围/射门/进球"；复用 shot/pass 高亮（头球=shot 带 detail=header，解围=pass），零新事件类型。

### D4: 界外球机制（Q4 grill 确认：复用 pass）

- 传球出边线 → **对方掷界外球**。
- 掷球：pass 高亮，起点=出界点（边线），落点=附近队友，短传无高度（h=0）。
- 复用门球"从固定点开球"逻辑（DeadBall 类型变体）。

**为什么**：界外球 = 从边线短传重新组织，复用 pass 高亮最简单。

### D5: 统一机制（Q9 grill 确认）

- 所有死球重开（门球/角球/界外球）都走 **DeadBall 状态机**（已建，加类型变体）。
- 所有球飞行都走 pass/shot 高亮；落点争抢都走松散球。
- 不新增架构。

## Risks / Trade-offs

- **[头球机制复杂度]**: 角球争抢 + 头球分支（射门/摆渡/解围）是本 change 最大增量。缓解：复用 shot/pass 高亮，只加决策分支。
- **[出界频率]**: 传球出界 3-5% + 扑出底线角球，每场角球 ~6-10 次、界外球 ~8-12 次。画面中断增多但真实。
- **[头球进球率]**: ~10% 角球进球率（真实 2-4%），偏高但保证观众偶尔看到头球破门。实施时可调。

## Migration Plan

- 引擎：DeadBall 加角球/界外球类型 + 出界判定（传球落点出界）+ 角球争抢决策 + 头球高亮产出。
- viewer：角球发球高亮 + 禁区争抢 + 头球演绎（头球射门=shot 带 header、解围=pass）+ 界外球掷球 + 出界视觉。
- 测试：引擎（出界判定/角球流程/头球解围/头球射门/界外球）+ viewer（角球/头球/界外球）。

## Open Questions

- 角球发球落点分布（禁区哪里）——实施时调参（近门柱/远门柱/禁区弧）。
- 头球射门/解围的具体概率（55/30/15 攻方、70/20/10 防方）——实施时可调。
- 出界频率（传球出界 3-5%）——实施时按画面节奏调。
