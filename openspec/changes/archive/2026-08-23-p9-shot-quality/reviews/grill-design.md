# Grill Design: P9 射门质量模型（shot-quality）

> 按 batch-grill-me 惯例，敲定设计细节。用户在 Open Questions 全部确认前，不写实现代码。

## 背景（facts，已从代码/实测确认）

- 当前射门：`emit_shot_highlight` 硬编码 goal 15% / saved 35% / off 50%，无位置依赖；射门槽固定间隔触发，carrier 在哪就哪射。
- L3 实测（200 场）：起脚位置 = 禁区内 14.5%、16.5-25m 10.8%、**25-35m 50%**、35-45m 11.8%、45m+ 12.9%；禁区内进球占比 12%；射正率 50%；转化 14.9%。
- 真实参考：射正率 ~33%、转化 ~10%、禁区内进球占比 ~85%、禁区内射门占比 ~55-58%、禁区内转化 14.7%、禁区外转化 4.2%。
- 头球射门全部来自角球争顶（禁区内），当前 goal 12% / saved 38% / off 50%。

## Round 1: 设计决策点

### Q1: 分桶粒度

按起脚位置给射门结果概率，分几桶？

- **A（推荐）两桶（禁区内 / 禁区外）**：禁区内 goal 15%/saved 30%/off 55%；禁区外 goal 3.5%/saved 16.5%/off 80%。加权（禁区内 55%）→ 射正 34%、转化 10%、禁区内进球 84%，三者同时对齐真实。简单、可校准、够用。
- **B 三桶（禁区内 / 禁区弧 16.5-25m / 远射）**：更细（弧顶 xG 0.05-0.10），但样本统计更稀、校准更复杂。
- **C 连续函数（按距离/角度）**：最真实但过度设计，远射/射正的连续概率需要大量校准数据。

理由：两桶已让三大比率同时达标；弧顶/远射的差异在集锦粒度上感知不强。B/C 留给 B 档做 xG 时再升级。

### Q2: 射门起脚位置修正——推进方式

carrier 距门过远（>30m）时，射门槽怎么「推进后射门」？

- **A（推荐）向前传球推进**：产 1-2 个向前传球高亮（传给进攻方向队友），球快速推进到射程内再射。复用现有 pass 机制；观感像「推进到前场再起脚」；1-2 步内到射程。
- **B carrier 带球推进**：carrier 向球门带球 K tick 再射。实现复用 carrier_move 推进分支，但长距离带球 8-10 tick 观感拖沓。
- **C 混合**：近的带球、远的传球——最灵活但状态机最复杂。

理由：A 用传球覆盖距离快（12-25 m/s vs 带球 5 m/s），且「传球进禁区再射门」就是真实足球最常见的进球路径；实现复用现有 pass 高亮。

### Q3: 射程阈值与推进上限

- 射程阈值 SHOT_RANGE_M：**30m**（禁区内 + 弧顶附近都算射程内）？还是 25m（更贴禁区）？
- 推进步数上限：**2 步**（传球推进）？还是 3 步？
- 超远（自家半场）时：推进 2 步后仍超射程就**强射**（宁可远射不丢射门槽）？

（默认：30m / 2 步 / 强射。实施时按起脚分布实测校准。）

### Q4: 头球处理

- **A（推荐）头球对齐禁区内桶**（goal 15%/saved 30%/off 55%）——头球都在禁区，口径统一。
- **B 保持现状**（12/38/50）——头球是角球派生，单独一套概率。

理由：A 口径统一、语义清晰（禁区外没有头球）；B 会让头球转化（12%）低于禁区桶（15%），且头球射正率 50% 拉高整体射正率。

### Q5: 进球数取舍（最关键）

转化率对齐真实 10% 后，按当前 7 射门/场，进球会从 1.06 降到 **~0.7/场**——「5min 集锦也要有进球」的 P7 需求受影响。

- **A（真实优先）**：接受 ~0.7/场。集锦无进球场次增多，但每粒进球都是「真实转化率下的进球」。
- **B（射门槽占比微调）**：shot 槽 30%→35-40%，射门 ~8-9/场，进球 ~0.85-0.95/场。微调保集锦进球，但仍低于真实 2.75。
- **C（禁区桶保底）**：禁区内 goal 15%→18%，进球 ~0.85/场，牺牲一点真实度。

（注：B/C 都只是把进球拉回 ~1 的量级，距真实 2.75 仍是数量级差距——那是 B 档的事。）

### Q6: 测试范围

- **A（推荐）本 change 启用 L3 gate（射门相关比率）**：射正率 [28%,38%]、转化率 [7%,13%]、禁区内进球占比 [75%,90%]、禁区内射门占比 [45%,65%]。
- **B 只做 L1/L2 断言，L3 继续 defer**：等 B 档密度扩展后再统一 gate。

理由：A 档第一项改的就是射门比率，改完就有资格 gate；B 会让这些比率回归无守护。

## Round 1 确认结果（2026-08-23）

- **Q1 分桶粒度 → B 三桶**（禁区内 / 禁区弧 16.5-25m / 远射 >25m）。概率（校准后）：15/30/55、7/22/71、4/11/85。
- **Q2 推进方式 → C 混合**：射门槽采样目标射门距离，carrier 已在目标内直接射；>40m 向前传球推进；否则带球精确落点推进（≤5 tick，步长 min(5m, 剩余)）；超上限强射。
- **Q5 进球数 → B 射门槽微调**：shot 槽 30%→35%，射门 ~8.4/场，进球 ~0.9/场。
- **Q4 头球 → A 对齐禁区桶**（15/30/55）。
- Q3（射程 25m / 40m / 2 步 / 3 tick）与 Q6（启用 L3 gate）按推荐定。
