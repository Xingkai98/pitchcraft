## 1. 120s 窗三方并排（真实 / 干净 main / 候选）

| | 非门将横向 sd | 非门将纵向 sd |
|---|---|---|
| 真实 Metrica | **10.04 m** | 14.35 m |
| 干净 main | 0.53 m | 3.06 m |
| 候选 | 0.47 m | 3.09 m |

**画面**：真实是满场交织的**网**（长距离带弯钩回环）；干净 main 与候选**都是同一种水平细轨**
（每人一条短横杠 + 一个点）。**候选与干净 main 同型——没有引入新形态。**
候选的路数在中心区更连贯一些（因为事件更密），但**结构没变**。

## 2. 全场窗（3600s）两方并排

| | 横向 sd | 纵向 sd |
|---|---|---|
| 干净 main | 0.76 m | 4.55 m |
| 候选 | **1.76 m** | 6.86 m |

**全场窗里候选的横向/纵向位移都上升到 ~2.3× / 1.5×**，画面上表现为**更长的对角跑动线**
（有几条贯穿半场的长直线）。结构仍是**水平带**（P38 的既有病灶），但球员覆盖的地面更多。
⚠️ 长直线**更直**（不是真球的弯钩回环）——见 §3 的直线度量化。

## 3. 量化「是否变差」（冻结判据种子 42/1/7/99/123，120s 窗，逐球员）

| 量 | 干净 main | 候选 | 读法 |
|---|---|---|---|
| 横向位移 sd | 0.64 m | **0.43 m** | 略**降**（真实 10.04 → 仍差 ~20×） |
| 纵向位移 sd | 3.51 m | 2.74 m | 略降 |
| 轨迹直线度（净位移/路径长） | 0.143 | **0.218** | **升**（更直、更少弯钩；真实是弯钩回环） |
| 净位移 | 4.98 m | 4.65 m | 基本持平 |

**诚实结论**：在**判据组的冻结种子上**，候选的横向移动**略降**、轨迹**略直**——
与判据组 `swarm` 由 ✅ 恶化到 ❌（0.488 → **0.338**）**方向一致、互相印证**。
**本 change 对「像不像真球」的横向形态是中性偏负的，没有改善**（这符合预期：本票不碰队形，
P38 §2.2 已证队形与体积在两根独立轴上）。

## 4. 与 P38 三次「数字达标但画面更差」前例的对比

| P38 前例 | 本 change |
|---|---|
| exp4b：等间距重排 → **铁轨换了方向** | 候选与干净 main **同型**（水平带未变） |
| 横向机制：**横贯全场的水平直线** | 候选有更长的对角跑动线，但**仍是同一族** |
| exp9-gated：**竖直铁轨** | 无 |

**判定：本 change 没有引入新的轨迹形态**；它放大的是**既有的**形态（更长/更多的水平带内跑动），
不是换一种病。这与判据组「七条几何原地不动、只有 swarm 与射门变」的机器读数一致。

## 5. 门球（唯一体积驱动的重开变化，+49%）

## 6. P5.5 结论

- ✅ **无新形态**（与干净 main 同族；轨迹结构与 P38 既有病灶一致）。
- ⚠️ **横向形态中性偏负**（latSd 略降、直线度略升、`swarm` 恶化）——**如实记录，不掩饰**。
  这是本票「不碰队形」的必然结果，不是本次改动的缺陷。
- ⚠️ 真实侧的「弯钩回环」形态**仍然没有**（P38 已知缺口，#89 的账）。
