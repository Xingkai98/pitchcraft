## 结构性红门的判定（这是决定性的一条）

方案 deadline 的 `far` 抢断**不是机制破裂**——是**浮点边界**：
```
冻结窗口 401..600: far=2  距离 = [12.001113, 12.002342]
3000 场:            far=25 最大距离 = 12.00755
```
全部在 12m 阈值的 **8mm 以内**。

**但「是浮点边界」不改变判定**：`assert_eq!(far, 0, ...)` 是**精确**断言，
冻结窗口上 deadline = 2 → **红**；方案 ③ 在同一窗口 = 0 → **绿**。
所以 deadline **引入了结构性红门**，且红门总数更多（默认套件 3 vs 2）、
角球 max 16 超出你拍板的 `≤15`。
