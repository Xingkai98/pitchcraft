## 二、第 2 轮拍板（用户已选）

### 决定 1：体积方案 —— **两个都做成补丁、跑全套门对照后再定**

不再预先押注。请把**两个方案**各做成可复现补丁，跑**完整的** `./verify.sh` + 判据组对照：

- **方案 ③（3 常量）**：`engageShift −3.4` + `BASE_DEF_TACKLE −0.65` + `BASE_DEF_FOUL −0.06`
  （射门 17.095 / 抢断 30.38 / 犯规 20.55 / 传球 396）
- **方案 deadline（2 常量）**：`engageShift −3.4` + `BASE_ACTION_DEADLINE_TICKS 6` + `BASE_DEF_TACKLE −0.70`
  （射门 18.695 / 抢断 30.07 / 犯规 18.13 / 传球 424）

**对照表必须逐条并列**（含各自的红门清单）：

| 维度 | 为什么它进表 |
|---|---|
| 射门 / 抢断 / 犯规 / 传球 | 与真实锚点的距离 |
| shot/tackle | 是否有带内余量 |
| **角球单场 max** | 方案③ 13 vs deadline **14**（grill 实测） |
| **`l1_tackle_dilution` 的 `far==0` 结构断言** | grill 说 deadline 会红（dist>12m 抢断出现 2 次）——**必须实测确认** |
| **判据组 8 条** | 含 `swarm` 的恶化幅度 |
| 常量个数 / 语义 | 定向杠杆 vs 全局节奏杠杆 |

**判定原则**（写进 design，供后人对账）：
- 若 deadline 方案**过全套门**且红门不多于方案③ → **选 deadline**（更少的常量、更贴锚点，符合 #102 教训）
- 若 deadline 引入**结构性红门**（`far==0` 这类）→ **选方案③**，并在 design 里写明「为何不用更简单的那个」
- 若两者各有红门 → 停下来报主 session，**不要自行取舍**

⚠️ **别忘 D2 的表要重做**：旧表把 `deadline` 放在 D3.3「排除」里，而**排除理由（与旧射门带冲突）在新带下已失效**。新的最简族必须包含 deadline 这一支，按「参数个数 × 落点质量」重新排序。

### 决定 2：射门带 —— **按真实侧分布推导，不照候选配**

用 StatsBomb **大五联赛子集**（n=170）：**mean 21.64 / sd 5.03**。
取 **±1.5 sd** → **[14.1, 29.2]**，取整 **`[14, 29]`**。

- **推导写进 design**：「带 = 真实侧均值 ±1.5 倍真实侧 sd」，并给出 n / mean / sd 的来源
- **候选读数只作对照，不参与定带**——这正是本 change 要消除的「按现状标定」
- 检查：方案③ 17.1 与 deadline 18.7 **都应落在 `[14,29]` 内**（若不，说明体积不够，报主 session）

### 决定 3：角球单场上界 —— **采纳 grill 的 `≤15`**

`≤18` 确认是纯比例外推、**无独立依据**。改用 **`≤15`**：
- 干净 main 3000 场 max = **12**（grill 实测，非 200 场的 9）
- 两方案 max 13 / 14
- `15` 守住「数量级护栏」语义，且余量极小 → design 要**如实写明余量很薄**

### 决定 4：抢断带 —— **修掉混口径**

grill 确认：StatsBomb `Duel/Tackle` **37.5** 与引擎 `tackle`（含失败两态）**同口径可比**；
WhoScored 的 **~30 是「成功抢断」口径**。design 把两者并排写成「真实」是**混口径**。

→ **锚 `Duel/Tackle` 37.5**（同口径），带按其分布定（方法同上，±1.5sd）。
**不要把 WhoScored 的 30 与 37.5 并排当「真实区间」。**

### 决定 5：接受 grill 的其余修正（无需再问）

- **B1**：补齐 4 条被漏掉的既有门（含默认 `cargo test` 里的

  以及 `l2_sent_off_kickoff_seeds` / benchmark 指纹哨兵）。
  **task P5.3「cargo test 全绿」是硬要求，必须真的达成**（不能靠删测试或放宽）。
- **B3**：改掉 D6 对角球长尾的**归因**——长尾来自**射门抬升本身**（`−3.4` 单跑 max 就 14），
  不是抢断；并补「干净 main 3000 场 max=12」这个更准的基线。
- **M5**：把 tasks P5.6 的「判据组不恶化」改成「**逐条对照并如实记录**」——
