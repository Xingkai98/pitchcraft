**给主 session** · 2026-10-13 · 分支 `p-form-track-x/2026-10-13`（fork 自 main `e587c7b`）
**结论一句话**：`FORM_TRACK_X` **确实是**「分边」的**真杠杆**（单调、可解析解释、读数命中预注册），

## 2. 我声称的因果机制（「因为改了 X ⇒ 量 Y 为什么降/不降」）

### 2.1 分边**为什么降**（解析 + 实测双证）

`formation_target`（`lib.rs:3440`）的块心：

```
block_cx = center0 + FORM_TRACK_X·(ball.x − center0) + attack_dir·(±FORM_CENTER_OFFSET)
center0 = FORM_CENTER_HOME 0.358（主）/ FORM_CENTER_AWAY 0.642（客）
```

两队**共用同一个** `FORM_TRACK_X` ⇒ 相减时**球的项被完全抵消**：

```
block_cx_home − block_cx_away = −0.284·(1 − FORM_TRACK_X)      ← 与球在哪无关
```

主 session 的 0.142（@0.5 ≈ 14.9 m）**复核为真**；`FORM_CENTER_OFFSET` 在「一队攻一队守」时对两队符号相同，也抵消。
**这是「分边被结构性钉住」的完整机制**，且它预测了一件事：**该间距随 `(1−TRACK_X)` 线性缩小**。

### 2.2 分边**为什么降不到真实**（这条是本次最重要的发现）

最终目标不是块心，而是 `tx2 = 0.5·tx_旧 + 0.5·block_tx`（`FORM_MIX_X = 0.5`），
而 `block_tx = block_cx + (base.x − center0)·FORM_SPREAD_X`，`tx_旧 = base.x + 球侧平移 + 压上`。
用 `default_lineup` 的外场 `base.x` 均值（主 0.460 / 客 0.642）：

```
目标点 x 间距 = 0.5·|0.460 − 0.642| + 0.5·[0.284(1−T) + 0.8·(0.460 − 0.358)]
             = 0.091 + 0.5·[0.284(1−T) + 0.0816]
```

| T | 混合后目标间距 ×105 m | 实测（seed 42 / 5-seed 均值） |
|---|---|---|
| 0.5 | 21.3 | 18.72 / 19.20 |
| 0.75 | 17.6 | 15.43 / 15.30 |
| 1.0 | **13.8** | 11.59 / 11.39 |

**即使 `TRACK_X = 1.0`，分边仍在 11–12 m ≈ 真实 5.24 的 2.2×** ——
因为 `FORM_MIX_X = 0.5` 把**一半权重**留给了**与球无关**的旧式站位表间距（0.182 ≈ 19.1 m）。
⇒ **TRACK_X 只能动"另一半"**。这条在跑 0.75/1.0 **之前**就写进了 `PREDICTION.md`（预注册），
预测 15.4 / 12.2 m，实测 15.30 / 11.39 —— **命中**。

### 2.3 画面**为什么反而更机械**（swarm 机制）

块心是**全队共用的一路信号**（记录 `p38-swarm-comes-from-common-signal`）。
`TRACK_X` 越大 ⇒ 这一路信号对目标的支配越强 ⇒ 全队随球纵向平移的幅度越大、越同步：

| 观测量 | 0.5 → 1.0 | 真实 | 含义 |
|---|---|---|---|
| `dir`（窗内位移向量两两余弦均值） | 0.79 → **0.85** | 0.70 | 越接近 1 = **全体同向**（整队平移） |
| `lat`（Σ\|dy\|/(Σ\|dx\|+Σ\|dy\|)） | 0.38 → **0.25** | 0.43 | 越低 = 越沿进攻轴滑（「铁轨」信号） |
| `disp`（位移/窗） | 6.00 → 9.26 | 13.46 | 跑得更多 |

三者同向 = **"跑动变多，但多出来的是整队一起沿轴来回滑"**。图（§3）与此一致：
1.0 的球员轨迹是**几乎贯穿全场的长水平线**，而真实是一团**短弧、密集在中路**的缠斗。

### 2.4 事件量**为什么膨胀**（0.75/1.0 破 L1 的机制）

**实测（事实）**：分边 19.20→15.30→11.39 单调下降的同时，事件量单调膨胀——
射门 22.1→28.3→29.5、抢断 41.5→49.1、角球 4.8→6.6、犯规 21.1→25.1，且主客进球方向反转。
**推断（未直接测量，标注为机制假设）**：中间的因果环是「两队块心靠近 ⇒ 双方球员在同一片区域
共处时间变长 ⇒ 接触/转换机会更频繁」——**我没有直接测"接触次数"或"共处时长"**，
这一步是从「间距↓ + 事件量↑ 单调同向」推出来的，若要坐实需另设探针（例如逐帧数 12m 内异队 pair 数）。
量涨到真实量级之外（射门带 [14,29] 上界、角球单场 max ≤15、射正率 ≤0.39），
且**主客进球方向反转**（0.75 起客队进球反超主队）——这正是 `FORM_MIX_X` 注释里记载过的
「球导向权重调高 ⇒ 主客进球方向反转」的同一族失效，只是这次走的是 `TRACK_X` 这根轴。

## 4. 推荐 + 下一步该动哪根轴

### 推荐：**`FORM_TRACK_X` 保持 0.5，不动。**

理由（按重要性）：

1. **封顶**：拉满（1.0）分边仍 11.39 m = 真实 2.17×，仍是损失表里**最大的缺口**（|ln|=0.78）。这根轴**解不了**这个缺口。
2. **代价已经付不起**：0.75 就破 L1 主客进球带（且方向反转），1.0 破 4 条带 + spacing 门。
   而基线本来就在几条带上贴得很紧（`禁区内进球占比 0.7211` vs 下界 0.72 = **0.0011 余量**；
   `射正率 0.3757` vs 上界 0.39；spacing 全场最小同队距离 2.149 m vs 阈值 2.0 m）——**没有向上的余量**。
3. **画面反着走**：数字（距离 0.520→0.438）单调变好，图（§3）单调变坏。**这就是飞轮空转三版的那个坑**，
   不要再交一版「数字更好、用户看不出」的配置。

### 建议主 session 换的轴（本次未动，仅给证据方向）

- **`FORM_MIX_X`（0.5）**：如 §2.2，分边的"半条命"在旧式 `tx` 上——那半是**与球无关**的站位表距离（0.182 ≈ 19.1 m）。
  它在 `tx2` 里占的权重就是 `FORM_MIX_X`。**要真正把分边压到 5 m 量级，必须动这半**（或动站位表本身）。
- **别用「更随球」当解法**：1.0 就是"最随球"，它把 swarm 推到最大。
  按 `p38-swarm-comes-from-common-signal`，问题的根是**块心这一路信号为全队共用**，
  所以在"随球度"上加码只会**放大**同步性；个体化必须换**信号源**（不是调增益）。
- 若确要试 TRACK_X 的小幅上移：**0.5–0.75 之间未测**（我只取三点），
  但 §1.2 的单调体积膨胀 + §4 的余量表说明窗口极窄，需与 `FORM_MIX_X` **联合标定**并重生成基线。
