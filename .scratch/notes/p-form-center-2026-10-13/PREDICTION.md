## 0. 轴的定义（只动这两个常数，对称收拢）

`engine/src/lib.rs:3417-3418`：

```
const FORM_CENTER_HOME: f64 = 0.358;   // → 0.40 → 0.45 →（附加点）0.50
const FORM_CENTER_AWAY: f64 = 0.642;   // → 0.60 → 0.55 →（附加点）0.50
```

记 `e = 0.5 − FORM_CENTER_HOME`（半分离）：基线 **0.142** → **0.10** → **0.05** → 附加点 **0.00**。
`G = FORM_CENTER_AWAY − FORM_CENTER_HOME = 2e`：0.284 → 0.20 → 0.10 → 0。

其余常数**一律不动**：`FORM_TRACK_X=0.5`、`FORM_MIX_X=0.5`、`FORM_MIX_Y=0.7`、`FORM_TRACK_Y=0.3`、
`FORM_SPREAD_X=0.8`、`FORM_SPREAD_Y=1.3`、`SIDE_SHIFT_FACTOR=0.06`、`FORM_CENTER_OFFSET=0.033`。

**附加点 0.50/0.50 超出任务书的三点**——它不是"再试一个更大的值"，而是**用来证伪我下面 §2 的
floor 预测**（不加这一点，floor 只能是外推）。同一条轴、同一对常数，未越界。

## 1. 解析模型（**测之前推导**，作为预注册的定量预测）

`formation_target`（`lib.rs:3440`）的最终 x 目标是两式混合（`FORM_MIX_X = 0.5`）：

```
tx_旧   = base.x + 球侧平移 + 压上                       ← 与 center0 无关
block_tx = center0 + 0.5·(ball.x − center0) + (±OFFSET) + (base.x − center0)·0.8 + ix
tx2     = 0.5·tx_旧 + 0.5·block_tx
```

对**同一名镜像球员**取主客差（主 `base.x = b`，客 `base.x = 1−b`），再对全队取均值
（`mean(base.x) = center0` 只在**基线**成立，收拢后不再成立——这一项是本轴的非线性来源）：

- 旧式那半：`Δtx_旧 = center_home − center_away = −2e`（球项、压上项对两队同号 ⇒ 相减抵消）
- 块那半：`Δblock_tx = −2e·(1−0.5) + 0.8·[(0.358 − center_home) − (0.642 − center_away)]`
       `= −e + 0.8·(−0.284 + 2e) = −0.2272 + 0.6e`

⇒ **最终目标点 x 间距（米）**：

```
gap_target(e) = 105 · |0.5·(−2e) + 0.5·(−0.2272 + 0.6e)|
              = 105 · (0.1136 + 0.7e)
```

| e（配置） | `gap_target` 解析（m） |
|---|---|
| 0.142（0.358/0.642 基线） | **22.37** |
| 0.100（0.40/0.60） | **19.28** |
| 0.050（0.45/0.55） | **15.60** |
| 0.000（0.50/0.50 附加点） | **11.93** |

**交叉验证这条模型**：C1 轴（`FORM_TRACK_X = T`）在同一推导下给 `gap_target = 105·(0.142 + 0.142·(1−T))`
= 22.37 / 18.6 / 14.9；C1 的 like-football 实测 = 19.20 / 15.30 / 11.39 ⇒ 比值 **0.858 / 0.823 / 0.764**。
（模型是"目标点"口径，实测是"实际位置"口径，系统性偏高 ~15-25%。）

## 2. ★ 预测（跑之前写死，测出来不符**必须**指出）

### P1 分边（`gap`，like-football 5-seed 均值，真实锚 5.24）
- `19.20 → ~16.2（0.40/0.60）→ ~12.8（0.45/0.55）`（用 ~0.83 的实测/解析比折算，区间 ±1.5 m）
- **⚠ 关键订正（与任务书给的预测不同）**：**不是"随 G 线性下降"**。分边对 `e` 线性（斜率 73.5 m/单位 e），
  但**截距非零**（11.93 m）。G 减 30% ⇒ 分边只减 ~15%；G 减 65% ⇒ 分边只减 ~30%。
- **P1b（floor 预测，最容易被证伪的一条）**：`e=0`（0.50/0.50，两队块心重合）**分边仍在 ~10 m**
  （= 真实 5.24 的 ~2×），**降不到真实**。
  **机理**：`tx2` 有一半权重压在 `tx_旧 = base.x + …` 上，这一半**与 center0 完全无关**，
  恒贡献 `0.5·0.284·105 = 14.9 m` 的**站位表本身**的队间距。`FORM_CENTER_*` **碰不到这半**。

### P2 核心假设：**画面不应更 rail**（这是本轴与 C1/C3/C4 的**全部差别**）
- `lat`（横向占比）：**0.38 ± 0.03**（不变）。真实 0.43。
- `dir`（方向一致性）：**0.79 ± 0.03**（不变；不进 ⚠ 偏离）。真实 0.70。
- `disp`（位移/窗）：**6.0 ± 0.8 m**（不变）。真实 13.46。
- 依据：`∂block_cx/∂ball.x = FORM_TRACK_X = 0.5`，**与 center0 无关** ⇒ 随球跟随增益一字未改。
- **图**：每个球员的**轨迹形状（长度、弯曲、方向）应不变**；变的只是**两色的相对位置**
  （红蓝向中线靠拢、重叠加深）。
  **若出现 C1@1.0 那种「贯穿全场的长水平线 / 两色叠成平行带」→ P2 被证伪，本轴的立论前提垮掉。**

### P3 结构性量（预测不变，理由：纯平移不改变离散度）
- 纵深 hd/ad：`39.10/36.67 → ±1.0 m 内`
- 紧凑度 spread：`20.83 → ±0.6 m 内`
- 宽度 width：`49.73 → ±1.0 m 内`（y 轴没碰）
- 球距 ballDist：**不预测方向**（±2 m），单列报告
- 混队度 mix：**预测上升**（`0.80 → 0.81~0.83`）——两队靠拢 ⇒ 异队近邻对变多。真实锚也是 0.80。

### P4 L1 逐带（`SEEDS_L1=200`，seed 401..600；主客带 `SEEDS_HA=600`，seed 401..1000）
- **预测：0.40/0.60 → 9/9 全绿；0.45/0.55 → 至少 1 红。**
- 若破，**最可能破的是体量族**，按可能性排序：① 主客进球带 `[0.85,1.60]`（C1 就是它先破的）、
  ② 角球单场 max `≤15`、③ 射正率 `≤0.39`、④ 射门/场 `≤29`。
- 机理（**记为"假设"，未直接测量**，与 C1 §2.4 同源）：两队块心靠拢 ⇒ 双方共处同区域的时间变长
  ⇒ 接触/转换更频繁 ⇒ 体量膨胀。**C1 在 TRACK_X 轴上看到实体量随 gap↓ 单调膨胀。**
- 反向可能：若静态收拢**不**改变球员—球 / 球员—球员的实际距离分布（因为 gain 与站位表离散度都没变），
  则 L1 全绿。**这是 P4 的对照分支，跑出来必须二选一。**
- 已知最薄的余量（基线实测，C1 §4）：`禁区内进球占比 0.7211` vs 下界 0.72（**0.0011**）、
  `射正率 0.3757` vs 0.39、`传球成功率 0.8424` vs 0.82 下界。

### P5 spacing-sweep（默认 8 seed，退出码须 0）
- **不预测**。基线余量只有 **0.149 m**（C1 实测整场最小同队间距 2.149 m vs 阈值 2.0 m）——
  任何扰动都可能破，且破了也**多半是"贴阈值的门 + 扰动"**（C1 §1.4 的判读），不是"队友被挤在一起"。
- 若红：必须同时给出「破的 pair / seed / 时刻 / worst 距离」，与 C1 的基线对照读数并列，不单独下结论。

### P6 距离（`like-football` loss）——**只记录，不当结论**
- 预测 `0.520 → ~0.47（0.40/0.60）→ ~0.44（0.45/0.55）`。
- ⚠ 它的下降**主要来自分边这一行**（分边是最大缺口 |ln|=0.78）。而分边有**退化方向**
  （`like-football` 头注释与 skill 均记：纯块配置距离最低、画面是两队叠在球上）⇒ **距离变好不能当验收**。
