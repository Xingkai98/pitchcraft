# 事件演绎剧本：带球 & 传球（票据 09 的讨论资产）

> 目的：把"引擎给数据、画面给戏"落到具体可讨论的**分帧剧本**。
> 原则：**先人后球、先动后停、动作之间有节奏停顿**。真实感来自节奏，不是位置精度。
> 数据支持：FM24 官方特性确认"持球时球员基于角色和队友相对位置主动跑位"——接球者**主动跑向落点**，不是原地等球。open-football 2D 未稳定，说明"事件→动画"映射最易被低估。

---

## 剧本一：带球（Dribble）——"踢-追周期"

### 引擎事件（协议层给什么）

```json
{ "t": 600.0, "type": "dribble", "from": "home#7",
  "x": 0.55, "y": 0.42, "x2": 0.62, "y2": 0.40,
  "speed": 3.2,        // m/s 带球速度
  "touch_freq": 1.2,   // 触球频率（次/秒）
  "result": "success" }
```

带球段 = 起点 + 终点 + 用时（由距离/速度推出）+ 触球频率。**引擎不逐帧算球**。

### 画面层演绎（人球解耦）

引擎给"带球 2 秒从 A 到 B"，画面把它演成 N 个"踢-追"小周期。设触球频率 1.2 次/秒 → 2 秒约 2-3 次触球。每个周期的节奏：

```
一个"踢-追"周期（约 0.8s）：
  phase 1  [人先动]  0.00-0.15s  人向前小冲一步，球仍在原位
  phase 2  [球弹出]  0.15-0.45s  球被踢出，向前滚（人减速，人球距拉大）
  phase 3  [人追上]  0.45-0.70s  人加速追上球（球减速）
  phase 4  [再触球]  0.70-0.80s  人伸脚触球，准备下一周期
```

**关键细节：**
- **人球分离量**：每次触球球滚出约 1.5-2 倍身位，人追回——这是"撞一下球"的视觉本质。
- **速度节奏**：人不是匀速，是"冲-停-冲-停"（phase1 加速、phase2 减速、phase3 再加速）。
- **球路**：球是"小弹跳/滚动"，不是完全贴地直线（可选：极小幅的上下起伏，模拟球在草皮弹跳）。
- **变向**：如果带球段带方向改变（x,y→x2,y2 不是直线），每次触球球的方向微调，人的朝向跟着转。

### 判定标准

2 秒的带球，画面看起来是"球员带球推进"，而不是"一个圆点拖着球平移"。**人球永远不完全重合**（除了触球瞬间），球始终在人的前方 0.5-2 身位。

## 剧本二：传球（Pass）——"传跑配合"

### 引擎事件

```json
{ "t": 650.0, "type": "pass", "from": "home#8", "to": "home#9",
  "x": 0.48, "y": 0.50, "x2": 0.68, "y2": 0.38,
  "ball_speed": 14.0,   // m/s 球速
  "lead": 0.6 }         // 传跑提前量：球是传到接球者"跑动前方"的落点
```

### 画面层演绎（人球解耦 + 传跑配合）

关键：**接球者先跑位**，球同时飞向落点，两者在落点"汇合"。

```
传球全程（约 1.2s，设距离 20m、球速 14m/s）：
  0.00-0.15s  [启动]   传球者摆腿（人轻微后仰），接球者开始启动跑向落点
  0.15-1.05s  [飞行]   球沿轻微外弧线飞向落点；接球者以节奏跑向落点
                       （注意：球是"飞"，接球者是"跑"，两个独立的运动）
  1.05-1.20s  [汇合]   球快到时接球者**减速刹车**，伸脚接球，人球合一
```

**关键细节：**
- **传跑不同步**：球不是等接球者到位才出发。接球者**启动早于球到达**，球到达时接球者刚好到位——这就是"传跑配合"。
- **落点有提前量**：`lead` 字段表示球传向接球者跑动方向的前方，不是接球者当前位置。接球者朝落点跑，不是朝球跑。
- **球路外弧**：中远距离传球画轻微外弧（脚法侧旋），短传接近直线。
- **防守者反应**（可选）：附近防守者会向球/接球者移动一步（预判），让画面更"活"。

### 判定标准

传球看起来是"8 号传了个好球，9 号跑到位接住"，而不是"球从 A 瞬移到 B"。**接球者的跑位是主动的**，不是原地等球。

---

## 两类剧本共通的演绎原则

1. **先人后球**：发起动作的球员先动（摆腿/前冲），球后动。
2. **人球解耦**：人球位置不绑定，靠"分离量"和"节奏"建立真实感。
3. **节奏停顿**：动作之间有微停顿（触球瞬间、接球瞬间），不是匀速流水账。
4. **双运动叠加**：球和人是两个独立运动（球飞、人跑），在落点"汇合"——这是传跑配合的视觉本质。
5. **主动接球**：接球者跑向落点，不是等球——FM24 官方确认的方向。
