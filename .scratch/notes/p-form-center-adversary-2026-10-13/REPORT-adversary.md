## 3. ★ 解析律：我独立推导（不看它的推导）

### 3.1 我的推导（从代码文本，非从报告）

`formation_target`（`lib.rs:3440`）最终的 x 目标：

```
tx2 = (1−MIX_X)·tx_旧 + MIX_X·block_tx        MIX_X = 0.5
block_tx = block_cx + (base.x − center0)·SPREAD_X + ix
block_cx = center0 + TRACK_X·(ball.x − center0) + attack_dir·(±1)·OFFSET
```

**对全队取均值（外场 10 人，`mean(base.x)` 主 `0.358`、客 `0.642`——我**从源码文本解析**
`home_rows`/`away_rows` 独立算出，并核了镜像对称 `max|home.x+away.x−1| = 0`）**：

```
mean(tx2)_home = 0.3222 + 0.25·ball + [shift/press/offset 项] − 0.15·h
mean(tx2)_away = 0.4278 + 0.25·ball + [同 上 项]              + 0.15·h
⇒ Δtx2 = 0.1056 + 0.3·h      （归一化）
⇒ gap_target = 105 × (0.1056 + 0.3·h)
⇒ ∂gap_target/∂FORM_CENTER_HOME = +31.5 m/单位（目标点口径）；×κ → ≈ +26.7
```

**我独立复现了 C2 的解析律，逐位相同**——包括「球项/压上项对两队同号、相减抵消」
（我逐项验过 `attack_dir·press` 与 `attack_dir·OFFSET` 的镜像配对恒等）、
以及「`Δtx_旧 = 0.284` 是**常数**、与 `center0` 无关」。

**符号与量级确认**：`+31.5 m/单位（目标口径）`，即 **反向**（收拢 ⇒ 分边变大）。
不是「我算出来和它一样」——是我**先**按代码推、**再**去比它的数，两边独立得到同一个式子。
