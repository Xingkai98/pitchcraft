## 3. 逐条判决

### 主张 1 —— 「没可行区间：gap 要进带必须 c ≤ 0.527，而 c=0.70 已破 4 条 L1 带 + spacing 门」

**✅ 确认。**
- 我用**自己的点**做插值：gap(0.60)=9.85、gap(0.55)=8.79 ⇒ 局部斜率 21.2/单位 ⇒ `gap=8.32` 在 **c≈0.528**（候选 0.527，同）。
- c=0.70 我实测：**4 条带断言破**（禁区内射门占比 / 抢断 / shot-tackle / 禁区内进球占比）+ **spacing 门破**。三个 test 红。
- ⇒ 「进带所需的最小压缩（c≤0.53）」比「门能承受的最大压缩（c=0.70 已红）」还小。**结论成立**。

### 主张 2 —— 「带穿越区间 gap [0.379,0.527] / hd [0.475,0.701] / ad [0.581,0.701]，三者交集空，缝宽 0.054」

**⚠️ 结论确认，但这张表有两处错（见 §4）。**

- ad 的上界 0.701 **是错的**（见 §4-2）。

### 主张 3 —— 「变体 A 只挪 gap、不挪纵深（hd/ad 差异 ≤1.1%）⇒ 恰好把两根杆对齐」

**✅ 确认（机制也对），但 1.1% 低估了 ad。**
我在**同一个 c=0.60** 上自建了 C 与 A 两个 wasm（同种子集），直接对比：

| c=0.60 | C | A | 差 |
|---|---|---|---|
| gap | 9.85 | **8.26** | **−16.1%** |
| hd | 22.75 | 22.99 | **+1.06%** |
| ad | 19.30 | 19.56 | **+1.35%** |
| spread | 16.92 | 17.05 | +0.77% |
| width | 49.66 | 49.61 | −0.10% |
| ballDist | 13.78 | 14.72 | +6.8% |

**解析佐证**（我自推）：`block_tx = block_cx + (base.0 − center0)·S`，其中 `block_cx = center0 + T(ball−center0) + …`
⇒ `block_tx = (1−T−S)·center0 + S·base.0 + T·ball + …`，`1−T−S = −0.3`。
改动 `center0` 只给**整队**的 `block_tx` 加一个**常数** `−0.3·Δcenter0` ⇒ **队内跨距（hd/ad）在目标层完全不变**，只挪块心（gap）。A 相对 C 的净效应正是「只挪 gap」。✔
（数值核对：c=0.60 时 Δcenter0 = ∓0.0568；`tx2` 权重 `M = FORM_MIX_X = 0.5`
⇒ 每队目标平移 `−0.3 × 0.5 × 0.0568 = ∓0.00852`（归一化）≈ **0.89 m** ⇒ 两队合计把 **gap 目标层压小 ≈1.8 m**；
实测 **9.85 − 8.26 = 1.59 m**，量级吻合。）

## 5. 我新发现的机制（候选未看到）

### 5.1 ★ 基线 spacing 门本来只有 **0.137 m（6.9%）** 余量，且**已经低于引擎自己的扫掠地板**

我写了一个**不开阈值**的探针，逐 2.5 s 窗扫整场、报所有同队 pair 的最小间距（seed 42）：

| **A 0.60** | **1.355 m**（pair **7,10**） | t≈423 s（球在中圈=开球重开） |

读数：
- 引擎自己的 `SAME_TEAM_MIN_DIST_M = 2.2`、扫掠地板 `SAME_TEAM_SWEPT_MIN_M = 2.14`；detector 阈值 `2.0`。
- **基线的最小值 2.137 m 低于引擎自己的扫掠地板 2.14 m**（低 3 mm），距 detector 阈值只有 **0.137 m**。
- ⇒ **spacing 门在基线上是「贴着带沿站」**（本仓的老坑）。任何把典型同队间距压小 >0.14 m 的改动**必红**——这解释了为什么 c=0.70（间距 −30%）不可能过，也把候选的「无可行区间」从「实测如此」升级为「**结构性必然**」。
- 同时它也说明：`spacing-sweep` 在这个轴上**不是一个有区分度的门**（基线余量 6.9%，任何有意义的压缩都会撞穿它），而更像一个**开关**。

### 5.2 ★ 破点对是**配置相关**的，不是结构唯一的

- C@0.70 → pair (2,4)（同 y、x 差 0.06 的那对；机制 = 传球接球者滑行被队友穿过）
