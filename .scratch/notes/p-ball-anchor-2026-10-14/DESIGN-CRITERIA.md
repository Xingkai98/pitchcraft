## 0. 一句话

把「每个球员钉在站位表上的一个**绝对坐标**」换成「一个**围着球、整块随球平移**的块，
站位表只提供**块内的相对形状**」。判据不是"某个数字变好"，而是**块跟不跟球 / 人聚不聚在球边 /
事件层付不付得起**这三条一起过。

## 1. 为什么必须换机制（五条轴全否的结论）

**现状的目标公式**（`engine/src/lib.rs:3440` `formation_target`）：

```
tx2 = (1−M)·(base.x + 球侧微移) + M·(block_cx + (base.x − center0)·SPREAD_X + 抖动)
       └──── 权重 50–88% ────┘        └─ block_cx 只**半程**跟球（TRACK_X=0.5）─┘
```

`base` 是**静态绝对坐标** ⇒ ① 球员离不开自己的车道（实测：最靠边的两人**每帧恒为同两个号码**）；
② 整块不会跟球平移（真实块心在窗内会整体偏出中线 **7.5–13.6 m**，引擎恒对称铺开）；
③ 人聚不到球边（球 12 m 内球员数 **真实 4.6–5.3 vs 引擎 2.60**；5 m 内接触率 **39% vs 3%**）。

**五条已死的轴**（`TRACK_X`/`MIX_X`/`SPREAD_X`/`CENTER_*`/站位表 x 压缩）都只是**在这个笼子里拧螺丝**：
拧小了够不到真实，拧大了要么变"铁轨/群体同步"、要么破事件层带、要么追的是 `max−min` 造的假缺口。
⇒ 结论：**要动的是"锚"，不是"增益"。**

## 2. 原型机制（怎么改）

```
rel   = base − 本队块心位          # 表只提供**块内相对形状**（均值 0）
block = ball + phase_offset(攻/守) # 块心 = 球（+ 攻守相位错开）；不再是 center0 + 半程跟随
target = block + rel · BLOCK_SCALE  # 块内铺开；BLOCK_SCALE 决定队的纵深/宽度
```

**四项参数，其中三项**从真实量直接定**（不拟合引擎）**，**只扫一项**：

| 参数 | 取值来源 | 建议值 |
|---|---|---|
| `phase_offset`（攻/守错开） | 真实：攻方块心在球前、守方在球后 | 由真实分箱实测定（先测再定，不拍脑袋） |
| `BLOCK_SCALE`（纵深/宽度） | 真实 `hd/ad ≈ 18–26 m`、`width ≈ 36–40 m` | 由真实带反解 |
| **个体的**差异化（**必须**） | `p38-swarm-comes-from-common-signal`：全队共用一路信号 ⇒ 必然同步 | 每名球员按**角色/离球距离**给不同的 commit 半径（不是全队一个 k） |
| **`ANCHOR` ∈ [0,1]（主扫变量）** | 0 = 现状（静态锚）、1 = 完全球锚 | 扫 0 / 0.25 / 0.5 / 0.75 / 1.0 |

⚠️ **`ANCHOR=1` 不等于 C1 试过的 `TRACK_X=1`**：那时 `MIX_X=0.5` 仍把一半权重留在静态 `base` 上。
本原型是**唯一一次**把 `base` 完全降为"相对形状"来试。

### G. 代价与失真的联合约束（防"数字对了画面更假"）
- **不许靠压扁换密度**：A1/A2 进带的同时，`hd/ad` 与 `width` **不得跌到真实带下沿之下**。
- **不许靠"全队叠在球上"换分边**：`mix` 不降 + `dir ≤ 0.75` + 盲测过关，三者同时。

## 4. 预注册的退化方向（见到即判负）
1. **群体同步**：全队一路信号 ⇒ `dir` 冲到 0.80+（C1 的 `TRACK_X=1.0` 就是这么死的：0.79→0.85）。
2. **两队同副本**：块心都钉在球上、模板相同 ⇒ 两队完全重叠（C5 判据镜记过：`MIX_X=1` 时 `block_cx = 0.5·ball + 0.25`，两队函数相同）。
3. **压扁成带**：为了"聚在球边"把块压小 ⇒ 纵深跌破真实下沿（y 轴 `S_Y=0.85` 那类"更扁的横带"）。
4. **数字好画面差**：本仓飞轮三版（v1 / v2g-g3 / FB4）的老坑 ⇒ 盲测一票否决。
