## 2. 我对 BRIEF §3 解析模型的复核（对照 `PREDICTION.md`）

**代数是对的，但它把一个拟合残差安错了名字；`spread` 那行算错了。**

1. **展开式 ✅**。`ty_f = (0.3+0.7·S_Y)·base.y + (0.35−0.35·S_Y) + 0.2208·(ball.y−0.5) + 0.7·iy`
   ⇒ 队内跨距 `= 0.6·(0.3+0.7·S_Y)`。基线 `68×0.726 = 49.37`，实测 49.73。
2. **残差 +0.36 m ❌ 不是 `iy`**。`iy` 幅度 ±0.056 归一化，但 `max−min` 的两个端点身份是**钉死的**（id5 落 0.137、次低 id1 落 0.258，差 0.121；id8 落 0.863、次高 id3 落 0.742）——**抖动换不了 argmax，一阶期望为 0**。
   我的机制探针直接证了这一点：`t0=600` 窗 451 帧里，home 外场两端**每一帧都是 id 5 与 id 8**（端点直方图 `5:451 8:451`）。
   **残差来源未知**，我列了候选（同队目标 repulsion / 已实现位置分离 / 追球者钉球位 / clamp 净效应），并如实标为**未定性**。
3. **`width` 线性 ✅（但只在 S_Y ≥ 0.85 成立）**。误差：1.1 → +0.08、0.95 → +0.17、0.9 → +0.13、0.85 → +0.28，**但 0.6 → +1.05 m**（模型预测 29.74，实测 30.79）。⇒ 我的预注册判别点 D1（±0.7 m）**在 0.6 处被自己的实测打脸**，如实记。
4. **`spread` 那行 BRIEF 算错 ❌**。它的公式 `0.383·√(a²+b²)` 代回基线得 24.2（实测 20.83），代 S_Y=0.9 得 21.0（它自己写 17.4）——**公式与它给的两个数都不自洽**。
   我用「均匀矩形数值解 + 基线标定」，预测 S_Y=0.9 → 18.1，**实测 18.55**（落在我的 [17.1,19.1] 内）；BRIEF 的 17.4 在带外 ⇒ **BRIEF 的 spread 预测被实测证伪**。
   我系统低 0.4–0.5 m（矩形不是 10 个离散点），但**斜率对**。
5. **三个内置对照 ✅，我给了证明**：两队外场 `base.y` 集合逐字相同、均值**恰好 0.5**，而 `ty_f` 是 `base.y` 的仿射函数、球项对全队是公共平移 ⇒ **两队重心 y 恒为 `0.5 + 公共项`，与 S_Y 无关** ⇒ `gap` 不变（实测 18.78–19.20）；`hd/ad/ballDist` 的目标式根本不含 S_Y。

### 3.2 机制（我声称的因果，逐条实测）

**A. 窄 y ⇒ 防守者更常落在抢断资格半径内（12 m）** —— ✅ 证实

**B. 窄 y ⇒ 传球落点更中路 ⇒ 边线出界通道变窄** —— ✅ 证实
传球落点 `|y−0.5|·68` 均值：**11.31 → 10.09 → 9.73 → 8.91 → 9.12 → 7.72**（monotone ↓）。

**C. 一条**反向**的结构发现（重要）**：**球位 `|y−0.5|` 不降**（20.25 → 18.09 → 16.20 → 16.52 → 18.32）。⇒ **球照样去边路，球员不再跟去**。本轴制造的是「球与人的横向错配」，不是一个「更紧凑的球队」。

**D. 到最近边线距离的分布（引擎 vs 真实，同一段代码）** —— ❌ 方向不利

## 7. 本轮真正的收获（可用结论，含对 C5 的订正）

1. **C5 的「spacing 0.137 m 结构性墙」是 x 轴特有的，不是通用的**。
   本轴把 `width` 压 25%（49.73→37.16），**整场最小同队间距只从 2.1372 → 2.1365 m（消耗 0.0007 m，0.5% 预算）**；`S_Y=0.6`（宽度 −38%）才降到 2.0616，**仍 > detector 阈值 2.0**。
   机制：基线最近的那几对（我 step=0.5 s 的实测是 `(18,15)@2191.5s`、`(2,4)@931.5s`、`(19,17)`、`(3,4)`、`(15,12)`、`(1,4)` —— **2.1365–2.1393 是一个「坪」，不是一对**）的间距由**已实现位置分离 + 扫掠早退**决定，**与块宽正交**；而 C5 压的是 x，直接吃掉了这些对的名义间距。
   ⇒ **后来者不必把 spacing 当通用否决项**；它是**「改 x 方向站位」的否决项**。
2. **`hd`/`ad`/`gap`/`ballDist` 对 y 轴解析不变**（并给出了证明）——这给了后来者一个**干净的正交旋钮**。
3. **剂量-反应 + 同引擎重掷零分布**，是把「真位移」与「地雷带」分开的**可行手段**，本轮用它救回了一条误判（`禁区内进球占比`）。**建议写进 spec / skill**。
4. **一条主 spec 级隐患（本轮顺带发现，建议单独立项）**：`禁区内进球占比` 的带 `[0.72, 0.92]`，**main 在种子 401–600 上实测 0.7211（余量 0.0011 ≈ 0.06σ）**，在不相交的 801–1000 块上**实测 0.7143（破）**。⇒ **这条带在任何改变 RNG 流的改动上近乎必破**。可能的解释：`sot/conv/inside` 三条比率带里，`inside` 的分布在 main 上**恰好骑在带沿**。**这是带的问题，不是轴的**。
5. **`Q`（压站位表 y）在等宽处略优于 `P`（改常数）**：距离 0.502 vs 0.507，L1 破 2 条 vs 3 条，机制读数几乎相同（12 m 内 1.471/1.674 vs 1.467/1.665）。⇒ **BRIEF 预期「改表代价更大」未被支持**（差异在噪声内，且方向相反）。这也侧面说明 C5 的「改表代价」主要来自**它同时改了 x**，不是「改表」这件事本身。
