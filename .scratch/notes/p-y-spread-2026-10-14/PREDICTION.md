## 1. 独立复核的验算过程（「因为」也要能被核）

### 1.1 展开式（我重推了一遍，与 BRIEF 一致）

`lib.rs:3471/3483/3485`：

```
ty    = base.y + (ball.y − 0.5)·0.06·0.6                    (旧式)
blk   = 0.5 + (ball.y − 0.5)·0.3 + (base.y − 0.5)·S_Y + iy
ty_f  = 0.3·ty + 0.7·blk
```

展开：

```
ty_f = (0.3 + 0.7·S_Y)·base.y + (0.35 − 0.35·S_Y)
       + (0.3·0.036 + 0.7·0.3)·(ball.y − 0.5) + 0.7·iy
     = (0.3 + 0.7·S_Y)·base.y + (0.35 − 0.35·S_Y) + 0.2208·(ball.y − 0.5) + 0.7·iy
```

⇒ 队内跨距 = `(0.3 + 0.7·S_Y) × 站位表 y 跨距`。外场 10 人 `base.y ∈ {0.2 … 0.8}` ⇒ 跨距 **0.6**（这一条我核过：把门将 id0/id21 的 0.5 剔掉后 min=0.2 / max=0.8，10 人名单逐个对过）。
⇒ `span = 0.6·(0.3 + 0.7·S_Y)`；`68 × 0.726 = 49.37`，实测 **49.73**。**代数没问题。**

### 1.2 残差 +0.36 m：**不是 iy**（BRIEF 归因错）

`iy = cos(phase + 1.3·id)·0.08`，进目标时乘 0.7 ⇒ 幅度 ±0.056 归一化 = ±3.8 m。
但 `max−min` 的两个端点**身份是钉死的**：S_Y=1.3 时 id5（base.y=0.2）落 0.137、次低 id1 落 0.258（差 0.121）；id8（base.y=0.8）落 0.863、次高 id3 落 0.742（差 0.121）。抖动幅度 0.056 **不到车道间距的一半**，永远换不了 argmax。
⇒ `E[max−min] = E[max] − E[min] = (0.863 + E[iy_top]) − (0.137 + E[iy_bot]) = 0.726 + 0`。**iy 对跨距的一阶贡献是 0，不是 +0.5 m。**

那么 +0.36 m 从哪来？我**没有解析答案**，只列出候选并标出可测性：
- (a) `compute_mover_candidates` 第二遍的**同队目标 repulsion**（`separate_pair_m`，阈值 2.2 m）把一对挤近的目标推开 ⇒ 可能把一个端点推得更外；
- (b) `commit_beat_positions` 的**已实现位置分离**同理；
- (c) 追球者 / `close_down` / `corner_setup` 把个别人钉到球位（球的 y 可以很极端）；
- (d) **clamp 的净效应**：`clamp01(ty)` 在球贴边线时（ball.y=1 ⇒ 平移 +0.1104，最外球员 0.863+0.110+0.056 = 1.029）**会触顶截断**——截断只压不扩，所以基线实测比纯模型**高**，说明 +0.36 的扩张源强于 clamp 的收缩。

**这决定了我的一个可证伪立场**：如果 +0.36 是**加性**残差（我的主预测），`S_Y=0.6` 应落在 ~29.7 m；
若是**乘性**（即模型本身少了 0.7%），应为 ~29.6 m——两者差 0.1 m，分不开，故本项**不设判别点**，只如实记「来源未知」。
**反证条件**：机制探针若显示失衡来自**单一极端帧**（如角球/重开）而不是分布整体外扩，则 §1.2 的 (c) 成立，(a)(b) 被削弱。

### 1.3 `spread` 的解析预测（BRIEF 的公式我算不出来）

BRIEF 写 `spread ≈ 0.383·√(a²+b²)`（a=39.10, b=width）。代回基线：`0.383×63.25 = 24.2`，**实测 20.83** ⇒ 公式在基线上就差 16%。
代 S_Y=0.9（b≈38.3）：`0.383×54.8 = 21.0`，**不是它自己写的 17.4**。所以 17.4 只能来自「以实测 20.83 为基准的**相对**缩放」。

我改用**数值解 + 基线标定**：
- 把 10 人瞬时队形近似成半轴 `(hd/2, width/2)` 的均匀矩形，数值积分求「到重心平均距离」`meanR(A,B)`；
- 用基线标定比例因子 `K = 20.83 / meanR(19.55, 24.87) = 1.2205`；
- 预测 `spread(S) = K · meanR(19.55, width(S)/2)`。

⇒ 预测值见 §3 表。**这是粗糙模型**（真实是 10 个离散点不是矩形），所以我在表里给 ±1.0 的带，并把「BRIEF 的 17.4 vs 我的 18.1」标成**判别点**。

### 1.4 三个内置对照的解析论证

- **`gap`（分边）不变**：两队外场 `base.y` 集合**逐字相同**（0.2/0.3/0.35/0.4/0.5/0.5/0.5/0.5/0.6/0.65/0.7/0.8 的同一组），均值**恰好 0.5**。`ty_f` 是 `base.y` 的**仿射**函数，球项对全队是**公共平移** ⇒ 两队重心 y 恒为 `0.5 + 公共项`，**与 S_Y 无关**。gap ≈ 19.2 由 x 分离主导 ⇒ 预测**不变**。
- **`hd`/`ad`（x 纵深）不变**：x 目标式（`block_tx`/`tx2`）**不含 S_Y** ⇒ 目标层完全不动；只有「位置→决策→事件」的间接反流可能带来小幅漂移。
- **`ballDist` 不变**：`ballDist = |home 重心 − 球|`，其 y 分量 = `(0.5+公共项) − ball.y`，与 S_Y 无关；x 分量不受 S_Y 影响。

### 1.5 我**主动放弃**的解析预言（不知道就说不知道）

- `disp` / `lat` / `mix` / `dir`（运动量四行）：它们不是我上面那个目标式能推的量（涉及路径、决策反流）。C5 的先例是「压 x ⇒ 四个量**全变差**」，但**机制不可移植**。我只给**方向性**预测（§3），不给精确值。

## 5. spacing 预注册（**与 BRIEF 相反**）

BRIEF：「y 变窄会把同车道队友挤近」⇒ 风险最高。
**我预测：本轴对已知破点是恒等的，spacing 大概率不破。**

论证（可逐字复核）：
- C5 判据镜实测的基线最近同队对是 id **(2,4)**（home，`base.y` **都是 0.5**，`base.x` = 0.20 / 0.14，间距 6.3 m 名义值）。

- ⇒ (2,4) 的**目标 y 差恒为 0**（两者 `iy` 相位不同 ⇒ 差是有界小量，且**与 S_Y 无关**）⇒ **本轴对该对的几何是恒等变换**。
- 因此：**spacing 若破，破点必然是别的对、或 dy 主导的时刻**——而这与 C5 的结论（破点 (2,4)，场景 `t=4049.5s`「追球者钉在球位上」）不同。

**可证伪的预注册**：
- **P5.1** `spacing-sweep`（seed 42）在 **S_Y ≥ 0.85 全部不破**（findings = 0，最小同队间距 ≥ 2.14 m）。
- **P5.2** 若破，我**点名 pair 与时刻**，并检查该 pair 的 `|Δbase.y|` 是否 > 0（=0 就是我的论证被反证）。
- **P5.3** 基线最小同队间距复现 **2.137–2.149 m**（C5 判据镜的值）。若我复现不出，说明是 seed/口径差，我照实记。
