## 3. 声称的因果机制

`formation_target`（`engine/src/lib.rs:3482`）：
```
block_tx = block_cx + (base.x − center0) · FORM_SPREAD_X + ix      // ix = 个体抖动
tx2      = (1−FORM_MIX_X)·tx_旧 + FORM_MIX_X·block_tx               // FORM_MIX_X = 0.5
tx_旧     = base.x + shift + attack_dir·press  [− push/clamp, 仅后卫]
```

**机制主张（解析，已逐位核）**：
1. 逐位算 `default_lineup` 非门将 `base.x` 均值 = **home 0.3580 = `FORM_CENTER_HOME`**、**away 0.6420 = `FORM_CENTER_AWAY`**
   ——即 **`center0 ≡ 本队外场 base.x 均值`**。
   ⇒ 块项 `(base.x − center0)·S` 的**队均值恒为 0**（`S` 不上队心），旧式 `tx_旧` 的队均值亦不含 `base.x`。
   ⇒ **目标点相对全队重心的纵向偏差 ≈ `0.5·(base.x − center0)·(1 + S)`**，即 **纵深 ∝ (1+S)**；
   **全队重心与 `S` 无关** ⇒ **本轴与「分边」正交**（这是 P2 的来源，0.6 上实测证实）。
2. `FORM_MIX_X = 0.5` 把**一半权重**钉死在「与 `S` 无关的旧式 base 站位表间距」上
   ⇒ **`S` 最多只能驱动纵深的一半** ⇒ **到不了真实**。反解：解析要 18.31 m 需 `S ≈ −0.21`；
   实测线性外推需 `S ≈ −0.05`。**两条路都落在 `S ≤ 0`**，即**本轴的可用区间 [0,1] 内无解**。
3. `S↓` 把球员投影到 x 上互相靠拢 ⇒ **同队最小间距下降 ⇒ spacing 门结构性破**（§1.4，单调 1/8→4/8 seed）。
4. `S↓` 使全队纵向压扁 ⇒ 球员被压进更窄的 x 车道 ⇒ **`lat` 降（更沿进攻轴）、`mix` 降（两队更不混）**
   ⇒ **画面更机械**（§1.5 图亲自确认）。

**可证伪条件（我登记过的）**：若 0.4 的 gap 离开 19.2 超 ±10%（<17.3 或 >21.1），则重心论证错。
**未触发**（18.06 = −5.9%）。若 0.4 的图红蓝混入中路一团，则 P5 错。**未发生**（图相反）。

## 4. 推荐

### **`FORM_SPREAD_X` 保持 0.8 不动。**
理由（按重要性）：
1. **方向对、到不了**：它确实单调压纵深（2.14×→1.60×），但**可用区间内无解**（要 `S ≤ 0`）。
   继续在 [0.4,0.8] 里拧，只是在「不达标」里挑一个更破门的点。
2. **门先破**：0.6 就破 2 条 L1（且都是**基线本就贴带沿**的带）+ 破 spacing；0.4 破 4 条 L1 + 4/8 seed spacing。
   **没有「既压纵深又不破门」的中间点**——0.6 已是最松的一步，仍翻车。
3. **只动一根杆 + 画面变差**：`分边`（真正的最大缺口，3.67×）**动不了**；`mix`/`lat` 双双恶化，图更机械。
   **净账为负。**

### 给下一根杠杆的指引（从本轴机制直接推出）
- **纵深的上限被 `FORM_MIX_X = 0.5` 锁死**——想动纵深，真正的杠杆是 **`FORM_MIX_X`**
  （把旧式 base 站位表那一半权重也换掉），或**直接改 `default_lineup` 的 base 纵向铺开**
  （现在外场 `base.x` 跨 0.14–0.62 = **50 m**，而真实纵深才 **18 m**——**站位表本身就太铺**）。
  在 `FORM_MIX_X` 未动之前，`FORM_SPREAD_X` 单独拧是**注定不够**的。
  （与 C1 对 `FORM_TRACK_X` 的同构结论：**两轴的拦路虎都是 `FORM_MIX_X`**。）
