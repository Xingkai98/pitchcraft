## 0. 解析基础（先算，再测）

`engine/src/lib.rs:3482`（`formation_target`）：
```
block_tx = block_cx + (base.x − center0) · FORM_SPREAD_X + ix      // ix = 个体抖动
tx2      = 0.5·tx_旧 + 0.5·block_tx                                 // FORM_MIX_X = 0.5
tx_旧     = base.x + shift + attack_dir·press [− push/clamp（仅后卫）]
```

**关键恒等式（本轴分析的地基）**：用 `default_lineup` 逐位算，
home 外场 `base.x` 均值 = **0.3580 = `FORM_CENTER_HOME`**；away = **0.6420 = `FORM_CENTER_AWAY`**。
⇒ `center0 ≡ 本队外场 base.x 的均值`（不是巧合，是定义对上的）。

两点直接推论（这就是我下面预测的**机制来源**）：
1. **目标点相对全队重心的偏差 ≈ 0.5·(base.x − center0)·(1 + FORM_SPREAD_X)**。
   （旧式项贡献 `0.5·(base.x−center0)`，块项贡献 `0.5·(base.x−center0)·S`；两式都随 `base.x−center0` 走。）
   ⇒ **纵深 ∝ (1+S)**，S 从 0.8→0.6→0.4 时纵深按 `1.6/1.8`、`1.4/1.8` 缩。
2. **全队重心与 S 无关**（`center0` 就是均值，块项与旧式项的**队均值都为 center0 + 平移/压上项**）
   ⇒ **FORM_SPREAD_X 不动「分边」（两队重心间距）**。

解析纵深（未加转向滞后）：`q10–q90` span × 105 m：

| S | 解析纵深 | 相对 0.8 |
|---|---|---|
| 0.8 | 41.96 m | 1.000 |
| 0.6 | 37.30 m | 0.889 |
| 0.4 | 32.63 m | 0.778 |
| 0.0 | 23.31 m | 0.556 |
| −0.5 | 11.65 m | 0.278 |

**实测/解析 标定系数**（基线实测 39.10 ÷ 解析 41.96）= **0.932**（转向滞后把目标 span 略缩）。
⇒ 预测**实测**纵深 = 解析 × 0.932：**0.6 → 34.8 m；0.4 → 30.4 m**。

**可达性（本报告要回答的核心问题）**：真实纵深 18.31 m。要让解析 span 落到 18.31/0.932×… 反解
⇒ **S ≈ −0.15 ～ −0.2**。**即：在 [0.8, 0.4] 内该轴离不了真实；即使把 S 拉到 0，纵深仍 23 m（1.27×）。**
根因：`FORM_MIX_X=0.5` 把**一半权重**留给了「旧式 base 站位表间距」——那一半**与 S 无关**。
（与 C1 对 `FORM_TRACK_X` 的同构结论：真拦路虎是 `FORM_MIX_X`，不是被扫的那个常数。）
