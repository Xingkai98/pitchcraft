## Question

**具体战术套路怎么做？——传球选人、跑位模式、整体逼抢。**

用户确认（2026-08-08）：**P7 = 战术决策系统**，包含三类具体战术意图。这是 P5 之后"真实比赛逻辑"的下一层。

## Scope（用户确认）

P5 解决"队形整体感 + 攻防态势"（真实感骨架）。P7 在骨架上加**具体战术意图**：

1. **传球选人升级**：当前 pass 用 `nearest_teammate`（找最近队友）。P7 改为**有意图地选人**——找边路空当（制造"传到边路"）、找前插队友（直塞）、找禁区（传中）。这需要评估"传球选项"（队友位置、防守压力、进攻价值）而非最近距离。
2. **特定跑位模式**：套边插上、包抄禁区、二过一（one-two）等**多球员联动跑位**。P5 的 movers 只做"向队形目标移动"，P7 加"战术触发跑位"（如传中时 2-3 名队友包抄点）。
3. **整体逼抢 / 高位压迫**：P5 只有就近 2 名 close_down。P7 加**全队压迫**（阈值触发整条防线压上逼抢）或阶段性高位压迫。

## 依赖与边界

- **依赖**：P5（队形公式 + 攻防转换 + micro-motion）稳定后实施——P5 的队形目标是 P7 跑位模式的基底。
- **关联票据**：wayfinder `04`（球场模型/战术系统）——P7 是票据 04 的落地核心。
- **与 P6 关系**：P6（定位球）提供死球重开，P7 提供运动战战术；两者独立，P6 先于 P7 或并行皆可。
- **建议顺序**：P5 → P6（定位球）→ P7（战术决策）。P7 最依赖视觉反馈调参（传中频率、压迫强度），应在其前两层稳定后进行。

## Suggested implementation

1. **传球选项评估**：从"最近队友"改为"评分候选传球"（距离 + 前向性 + 防守压力），支持边路/直塞/传中意图。
2. **战术跑位触发器**：高亮事件（传中/直塞）触发 2-3 名队友的包抄/插上跑位（movers 叠加战术目标）。
3. **整体压迫阈值**：球在对方半场 + 对方持球时，全队前压逼抢（防线压上 + 中场贴抢）。
