# 接出「意图」类观测并重跑 phaseability gate

- Type: research
- Status: resolved（2026-09-30；PR #127 已合入。裁决：**仍不够**——见文末「结论」）
- Created: 2026-09-29
- GitHub issue: https://github.com/Xingkai98/pitchcraft/issues/124（`wayfinder:research`）
- Blocked by：P16（GH #121 / PR #123，已合入）
- 下游：#15B（判据）、#17B

## 为什么立这张票

P16 的裁决是**部分够**：只有 `final_third` 可判（AUC 0.855/0.862），
`build_up`/`progression` **判不了**（0.461/0.431）。P16 的审阅者**自己扫了 21 个空间量**，
最强非循环量只 0.634 ⇒ **「空间量本身不足」**，继续加空间特征救不了。

P16 报告点名的缺口：**能表达「意图」的观测**（射门窗口开启信号、防守方位置/线路）。

## 关键前提：这是「把已有的接出来」，不是造新机制

| 信号 | 引擎内有 | 在 sidecar |
|---|---|---|
| 位置 `st.pos` | ✅ | ❌ → P16 G1 已接出 |
| `transition` 窗口 | ✅ | ❌ → #113 已处置 |
| **`shot_setup` / 起脚窗口** | ✅（`lib.rs` 多处） | ❌（`observation.rs` **0 处**） |
| **防守方位置 / 线路** | ✅ | ❌（`state_snapshots` 有位置，缺防守意图） |

⇒ 与 G1 同法：只加**只读**观测，**不改 `ControlFact` 闭集、不改正式事件流、不动决策**。

## 必须先做的前置：净化 motif 混淆

P16 已指出未净化变量（`build_up` 与 `progression` 在「传球数」与「是否重开」上同时不同）。
主 session 交付前跑过一轮净化（30 seed，`forward_m/s`）：

| 臂 | 定义 | AUC |
|---|---|---|
| 当前定义 | 重开 + 传球数同时不同 | 0.461 |
| 抽掉「是否重开」 | 只留传球数 | 0.437 |
| 抽掉「传球数」 | 只留是否重开 | 0.490 |
| 两个都抽掉 | 空对照 | **0.500** ✓ |

⇒ P16 的裁决**不是混淆造成的假象**；但接入新信号后**必须再净化一次**。
（主 session 探针曾因 `flatten` 压缩索引空间而给出错的 0.493——**反证条抓住的**；
接入后重跑时同样要带反证条。教训：**参考集下标与特征下标必须同处一个索引空间**。）

## 验收

1. 新信号进 sidecar（只读；`simulate()` 逐字节一致门仍绿）；
2. 重跑 phaseability gate，看三档 AUC 是否改善；
3. 净化 motif 混淆（同 P16 做法）；
4. **明确裁决**：够（给谓词）或不够（点名还缺哪类观测 + #15B 的处置）；
5. **不得用区域/坐标冒充战术阶段**；若只能用几何代理，须命名为**证据**，不得复用 `Phase`。

## 边界

不实现 15B；不改跑位/决策逻辑、RNG、正式事件流协议、viewer 正式播放。

## 结论（2026-09-30；PR #127 / merge `6abc5ef`）

**裁决：仍不够。** 意图观测已按本票接出（只读、零引擎行为改动），
但 `build_up`/`progression` **依旧判不了**。

- 全部**样本充足的非循环**意图特征落在 **0.449–0.546**（|Δ|≤0.06）⇒ 与随机无异；
- `final_third` 可判，但**靠几何证据**（`forward_m/s`），不是战术意图。

⚠️ **本轮最重要的发现（循环性）**：`window_*` 三条对 `final_third` 的 AUC **0.966** 是**同义反复**
——非头球射门只由起脚窗口产出，窗口预算 ~1 拍、恰是**射门前一拍**（实测 493/541）。
**leave-one-out 剔除该拍后 0.966 → 0.510**。⇒ 0.966 不是证据，是定义；实现期曾有守卫在**保护**它。

**给 15B**：`final_third` 若用 `forward_m/s`，须命名为**证据**（如 `GoalwardProgressEvidence`），
**不得复用 `Phase`**；`build_up`/`progression` 保留 `unknown`。

⇒ **与 P16（GH #116）合读**：空间量（#16）与意图信号（#124）**两条路都试过、都不够**——
phase 判据目前**没有**可用的观测依据。见 roadmap §5.1/§5.2。

**审阅闭环**：7 轮独立只读审阅（6 轮不放行 → 第 7 轮放行）+ 合入时 3 轮增量复核；
记录含 agent id 留痕，见 `openspec/changes/p124-intent-observations/REVIEW.md`。
