## Question

**事件引擎核心用什么语言？**（已与"画面层语言"拆分——引擎核心是纯逻辑，数据进、事件流出，平台无关，将来可平移。）

候选：C++ / Rust / JS。
硬约束：从零写、不依赖现成的 FM 类实现；通用工具允许。

## Answer

**Rust。**
- 理由：用户希望未来长期深耕（"未来还是要把这个好好搞一搞"），Rust 是长期投资。
- 与画面层解耦：引擎纯逻辑、平台无关；桌面走 Tauri 原生（Tauri 后端即 Rust）、网页走 WASM。
- 一套 Rust 核心，桌面原生 + 网页 WASM 两头跑，无需二次平移。

> 关联：`07` 画面层 JS+Canvas（双端）；`08` 运行时拓扑（如何协同）。
