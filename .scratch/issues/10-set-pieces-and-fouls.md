## Question

**定位球（任意球/角球/点球）在两层架构里怎么做？——含触发规则层。**

用户确认（2026-08-08）：**任意球、角球、点球全部放 P6 做**。P6 之前（P4 并行节拍核心、P5 队形/转换/micro-motion）不含定位球。

## Scope（用户确认）

- P6 范围：**任意球 + 角球 + 点球**（三类定位球）。
- 隐含前置：这三类都由 **犯规 / 出界 / 禁区内犯规** 触发 → P6 需要一个"规则层"（foul 判定、out-of-play 判定、禁区事件），当前引擎没有。

## 技术归属（已定架构）

| 环节 | 归属 | 现状 |
|------|------|------|
| 触发判定（犯规/出界/点球） | 引擎主循环新增规则层 | 无——off_target 直接 kickoff，无 foul/out 概念；tackle fail 不是犯规 |
| 定位球重开流程 | 扩展 `advance_dead_ball` 状态机 | 已有骨架（庆祝→whistle→准备→kickoff），加"定位球位置+球权方+类型"变体 |
| 定位球本身（球飞行/人墙/门将扑救） | 复用现有高亮事件（pass/shot 高亮） | 高亮门控 + 参与者排除 + viewer 两层合成已就绪 |
| 画面演绎 | viewer 两层合成 | 已完成 |

结论：定位球不是独立系统，是"死球重开流程"的扩展 + 一个规则层前置。工程上便宜。

## 具体场景（用户反馈 2026-08-08，P6 开发前补充）

### 场景 1：射门打偏 → 门球（goal kick，守门员开大脚 + 中场争抢）

用户反馈（原话提炼）："射门没打到门范围 → 球在出界处停一段时间 → 从原地直接飞中圈"不对。真实足球出界后应是守门员重新发球。

**目标流程**：
1. 射门打偏（off_target）→ 球飞到界外（钳制在边线外，可有出界视觉）。
2. 球到对方守门员脚下（**瞬移可接受**——不要求滚动动画）。
3. 守门员**开大脚**：球从门线飞到中场（高亮事件，起点=门线、终点=中场落点，高速长球）。
4. 中场落点**无人持球** → 松散球（`beat.ball loose:true`）。
5. **双方可争**：复用现有"双方可争"松散球模式（`nearest_any`——双方外场都能追球），最近者拾取 → 恢复 main → 开放比赛。

**现状**：off_target 走"中圈 kickoff"（错误的重开类型）。链路（高亮飞行 → 松散球 → 双方追逐 → 拾取 → 恢复持球）P4 已建成，只需把 off_target 接到门球后面。

**需要微调**：
- off_target 后 possession 切到对方（门将 = 对方门将）。
- "无接球者"的大脚：现有 pass 高亮要求明确 to；需支持无 to 的长球（复用 kickoff 事件或 to 可选）。
- 门球是否触发 transition（球权易主）：讨论倾向——开大脚是高球权转换，可触发（纳入 P6 设计时定）。

### 场景 2：进球 → 球直接跳回中圈 + 开球

用户反馈："进球后从原地直接飞中圈然后开球，是对的；希望球直接到中圈，然后准备开球。"

**目标流程**：
1. 进球确认（球越过门线进网，视觉区分 goal vs saved/off_target——门将/球网表现加强）。
2. 球**直接跳回中圈**（不做"从门内滚回中圈"的 2 秒过渡——死球→kickoff 本就有 spec 允许的瞬移例外）。
3. 开球者（被进球方前锋）走向中圈开球（现有流程保留）。

**现状**：进球后从门内滚回中圈（2s 过渡）。改为直接跳回中圈即可。

**扩展（后续）**：谁去把球捡回来放中圈（进球庆祝的真实演绎）。

## 建议实施顺序（含场景）

1. **P6 首批（本轮反馈优先）**：
   - 场景 1：off_target → 门球（守门员开大脚 + 中场双方争抢松散球）
   - 场景 2：进球 → 球直接跳回中圈
2. **P6 后续**：foul 判定（tackle 越界/禁区手球）、出界判定、角球/界外球/任意球重开（复用 DeadBall 状态机）。这是定位球的**最大前置依赖**（没有犯规/出界判定，定位球无从触发）。
3. **P6 或 P7**：点球（禁区内犯规判定 + 点球点高亮）。
4. 越位规则建议同期或稍后（影响进攻跑位，与定位球触发有交集）。

## 关联

- 定位球触发的犯规/出界判定 = 新"规则层"，是 P6 立项时的设计焦点（OpenSpec change proposal 时需 grill：犯规判定参数、点球判罚概率、角球/界外球/任意球的触发分布）。
- P4/P5 的 Non-Goals 均已把"完整比赛规则（越位/界外球/定位球）"标为"之后"→ P6 落地。
