## 为什么立这张票

`#19` 证明**最小单点改造不存在**——真因是**引擎贴着 L1 带沿站**（余量 1–6%），
而射门/抢断/犯规由**同一处接触几何**驱动（防守者到持球者的距离，既决定持球者出球门、
又决定防守者抢断/犯规资格线）。**单点改必破另一带。**

⇒ 要动引擎必须**协调地动 ≥2 处**，且**很可能要同时重标定某条带**。
**但在动手之前，必须先把「目标态」定义清楚**——否则又会变成「改完发现破带所以放宽」。

## 问题

1. **哪些量必须同时抬**？（射门 / 抢断 / 犯规 —— 三者都低于真实）
2. **各自抬到哪**？（真实侧已知：射门 ~21.6、抢断 ~36.9、比值 ~0.586）
3. **哪些量必须不动或反降**？（`shot/tackle 比值`、射正率、转化率、传球成功率）
4. **同时抬的机制前提**（要动哪几处、为什么）
5. **重标定代价**（若必须动带，动哪条、依据是什么）

## 边界

**零引擎改动、零带改动**；纯研究；产出供用户拍板是否开「更大的 change」。

## 结论（2026-10-02 填）

> 全文与出处行号见 `.scratch/notes/143-target-state-2026-10-02.md`。引擎读数用本 worktree
> 从 main 源码重建的 wasm，`cargo test --test realism`（9/0）与 `l1-metrics.mjs` JS 复算**逐位一致**。

### 1. 票面前提需修正：**只有两条量低于真实，犯规不是缺口**

| 量 | 真实值（口径+出处） | 引擎现值（本 worktree 实测） | 缺口 | 方向 |
|---|---|---|---|---|
| 普通射门/场 | **21.64**（StatsBomb n=170，`realism.rs:707`） | **17.095** | −4.55 / **−21.0%** | **抬** |
| 抢断/场 | **36.90**（StatsBomb `Duel/Tackle` n=170，`realism.rs:752`） | **30.38** | −6.52 / **−17.7%** | **抬** |
| 犯规/场 | **~20–21**（Kopacak/Metrica/WhoScored，`report.md:133`） | **20.55** | **≈ 0** | **不动（守住）** |
| shot/tackle | 0.586（=21.64/36.90） | 0.5627 | −0.024 | **随分子分母到 0.586** |

**犯规（20.55）已在真实 ~20–21 内**——`p104/design.md:270` 与 `proposal.md:17` **原文即写**「犯规本来就对，
不是缺口」。故「三者都低于真实」是票面 §1 的**待核项**，核实结果是**犯规不在其中**。
这**不是「真实值自相矛盾」**：真实侧 shot/tackle/foul 在真实比赛里同时成立，是本票的**候选清单多列了犯规**。

### 2. 目标态自洽（不矛盾）

把两条量**同口径**抬到真实（射门 ×1.266、抢断 ×1.215），ratio 自然到 **0.5865 ≈ 0.586**；
进球随射门抬（conv 是固定桶常数）→ 总进球 ≈ **2.7–2.8** ≈ 真实 2.75。⇒ **目标态内部一致**。

### 3. 机制前提：**走 tendency 常量族，不走 #19 的几何路**

- **几何路（禁区）**：#19 已证伪——同一「防守者到持球者距离」同时驱动压力门（`OPEN_PLAY_PASS_PRESSURE_M`=8.0，
  `lib.rs:1836`，与 `SHOT_PRESSURE_NEAR_M` 同数）与抢断/犯规资格线；拉近防守者必挤掉射门 ⇒ 当前带下无可行区间。
- **tendency 族（可行）**：#104 实证射门杠杆 `OPEN_PLAY_SHOT_ENGAGE_SHIFT`（`lib.rs:598`）**不动**抢断/犯规
  （shift −3.4 时抢断仍 9.00 = 干净 main）⇒ 射门与防守饼**经验解耦**。
- **候选改动（给候选，不设计实现）**：**{M1 射门常量 `OPEN_PLAY_SHOT_ENGAGE_SHIFT`，M2 抢断常量 `BASE_DEF_TACKLE`，
  M3 犯规补偿常量 `BASE_DEF_FOUL`}**——三者**必须同时动**：M2 会从同一块防守饼切走犯规（#104 实测切到 16.98）⇒ 必配 M3；
  M1 单独动会冲高 ratio、M2 单独动会压低 ratio ⇒ 必配 M1+M2 一起把 ratio 稳在 0.586。

### 4. 重标定代价：**三条核心带无需动**

射门 `[14,29]`、抢断 `[24,50]`、ratio `[0.5,1.5]` **本就从真实推导、中心即目标** ⇒ 抬到目标 = 从带沿移到带心，**更安全**。
有风险的只是**既存债**：`sot`/`conv` 上界按引擎现状配（= **#140**，open）与角球单场护栏 `≤15`——修法已定为
「按真实重推 / 承认自定护栏、朝真实」，**不是**「改完破了才放宽」。

### 5. 遗留不确定（详见 note §6）

犯规真实锚与射门/抢断**不同源**（StatsBomb 犯规列在 repo 内空缺）；**到目标的幅度可达性未证**（属下一步 change，本票不做）；
`sot`/`conv`/角球长尾在更高射量下的漂移未测；**传球（395.9 vs ~900）、角球（3.19 vs ~10）缺口不在本票 target 内** ⇒ 本票是「部分目标态」。
