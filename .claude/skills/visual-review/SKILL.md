# visual-review：引擎画面「像不像足球」的独立审阅回路

**为什么有它**：本仓的统计带（L1：射门/抢断/犯规…）**测不出「画面像不像足球」**——
P143r 实测「射门/抢断调到真实值、过全部统计门」的版本，**画面在用户眼里毫无变化**。
而「球员 87% 时间静止」这种**过程缺陷**，统计带看不见。所以要一条**看画面**的独立回路。

**核心纪律（踩过坑，别省）**：
1. **单帧会骗人、稀疏采样会骗人**：必须在**短窗（12s）内密采 6 帧**，才看得出「动没动」。
2. **喂给视觉模型的图本身要自证**：曾因把引擎的球（数组 `[x,y]`）当对象 `ball.x`，
   球**从来没画出来**，裁判连续多轮「看不到球」，主 session 误判成「球点太小」。
   → `render.mjs` 已统一口径、球画成**亮黄大点**；测试 `visual-review.test.mjs` 守这个。
3. **打分的必须与改代码的分离**（用户 2026-10-03 要求）：**主 session 改引擎，打分另起一个
   零上下文 agent**（paseo agent）。主 session 只读它的记录，不改它的分。
4. **运动指标别挑窗**：曾报「静止率 3%」实为**单窗（高活跃窗）**挑出来的，全 match 是 56%。
   → `motion-metrics.mjs` 跨**全部窗**算、报中位与样本数。

## 三个工具（都在 `tools/visual-review/`）

| 工具 | 作用 | 用法 |
|---|---|---|
| `render.mjs` | 渲对比图（上引擎 6 帧 / 下真实 6 帧，亮黄球） | `node tools/visual-review/render.mjs <engine.wasm> <out.png> [seed=42] [t0=600] [win=12] [n=6]` |
| `ask-vision.mjs` | 把 PNG 交视觉模型判读（修了 vision.py 的 max_tokens 陷阱） | `node tools/visual-review/ask-vision.mjs <png> "<问题>"` |
| `motion-metrics.mjs` | 运动真实性指标（端点位移/窗、方向一致性、静止占比），跨全窗 | `node tools/visual-review/motion-metrics.mjs <engine.wasm> [seeds=5] [win=12]` |

真实对照用 `viewer/data/real-game-1.json`（P35 Metrica 通路）。⚠️ **它被 gitignore（不入库）、CI 不产**——
生成方式：`node tools/fetch-tracking-data.mjs && node tools/convert-tracking-to-frames.mjs`；可用 `VISUAL_REVIEW_REAL` 覆盖。
⇒ **`render.mjs` 在 CI 上跑不了**（缺 wasm + 真实帧）；所以**守护测试用合成帧**（不依赖它们，CI 必跑）。

## 流程

1. **渲图**：对目标 wasm 跑 `render.mjs`（**口径固定 seed=42 / t0=600 / 12s 窗 6 帧**，否则跨版不可比）。
2. **看图**：主 session **先自己 Read 图**作 sanity check（能读图），再交独立裁判。
3. **独立打分**（paseo agent）：给它 wasm 路径 + 口径，让它渲图 + `ask-vision.mjs` 判读 +
   按**固定 6 维**打分（见下），追加进 `RECORD.md`，**带全口径**（图路径/seed/t0/wasm sha8/原文）。
4. **运动指标**：`motion-metrics.mjs` 拿客观数（位移/方向一致性/静止），与真实对照。
5. **决策**：像不像分 + 运动指标 + （另跑）**L1 统计门**，三者一起看——**统计全绿 ≠ 画面像**。

## 固定 6 维（每次必须全答，跨版可比）

1. 引擎相邻帧球员位置变化（几乎不变 / 有些 / 很大）
2. 真实相邻帧变化（对照）
3. 引擎球员分布（均匀铺满 / 聚在局部 / 机械分边）
4. 引擎红蓝是否交错（交错 / 半边各一 / 混合）
5. 引擎有无局部聚集（争抢/盯人/接应）（有 / 少 / 无）
6. **像不像真实足球（1–5）** + **最不像的一点**

## 已知盲区（如实带过，别掩盖）

- **传球/球权类改动，视觉回路测不到**：12s 窗平均仅 ~0.8 次传球，装不下「球在球员间流动」。
  P5（弹球 60%→10%）画面分纹丝不动。→ 这类改用**事件流探针**（弹球率/接球熵）。
- `motion-metrics` 的**方向一致性**区分度有限（本仓校准：main 0.62 / 真实 0.67，
  不如裁判自定义口径分得开）——**趋势可用，别当绝对门**。
- 视觉模型判读有噪声：同一张图重复判读可能跨 1 分；**不确定就重复判读 + 报一致性**。

## 产物落哪
