# adversarial-explore：带对抗的探索回路

**为什么有它**：本仓反复栽的三类错，**都是「单视角验证」抓不到的**：

- **结论对但机制错**（`conclusion-right-mechanism-wrong`）——机制描述与代码不符，审阅只看结论就放过。
- **数字全绿、画面没变**（飞轮空转三版，见 `visual-review` skill 的「飞轮为什么空转」）。
- **必要性主张没试最简解**（`necessity-claims-need-the-simplest-competitor`）。

单线「实现 → 跑数字 → 下结论」必然漏网。所以要**多镜头 + 对抗**：候选由**独立 agent** 产出，数字与画面由**不同镜头的零上下文 agent** 独立复核与**试证伪**。

**首次实跑（2026-10-13，C1 `FORM_TRACK_X` 轴）**：对抗层改了 **4 处**——① 一处**算术实错**（把「目标量」与「站位表量」相减）；② 一处**低估**（「非系统性」说轻了：位移其实系统性，破不破线才偶然）；③ 一处**漏免责**（那条判据基线自己就 5 窗反 2 次，无判别力）；④ 发现 **`like-football` 的距离标量有退化方向**（纯块配置距离 0.365 全场最低，画面却是两队叠在球上）。证据：`.scratch/notes/p-form-track-x-2026-10-13/`。

## 流程（四步；②③ 用 subagent，paseo 托管）

### ① 主 session「先看」+ 列候选

- `node tools/visual-review/trajectory.mjs <wasm> <out.png> [seed] [t0] [win]` 渲「引擎 vs 真实」**多窗**，**Read 完写下一句话**（不许跳）。
- 读码定位机制——**算出结构性关系**（例：「两队共用同一常数 ⇒ 块心间距恒 = f(常数)，与球无关」），别只描述。
- 产出**候选杠杆清单**，**优先最简解**（改常数 > 改机制）。
- 用**该 worktree 现建的 wasm**（别拿旧实验产物；见 `stale-local-engine-wasm-false-red`）。

### ② 候选层（每候选一条轴 = 一个 agent，各自 worktree/分支隔离）

- 每轴扫 **≥3 个点**（基线 + 两侧），每点**从本 worktree 源码重建 wasm**。
- 每点跑**同一套面板**：`like-football` **距离 + 目标两根杆**、**L1 逐带实测值**（不是只报 9/9）、`spacing-sweep`、**轨迹 png**。
- 落盘：读数表（**口径齐全**：wasm sha + seed + 时长 + 源码状态）+ png + **它自己声称的因果机制**（供人打）+ **预注册**（先写下预测，再测）。

### ③ 对抗层（每候选 ≥2 个不同镜头，零上下文，并行）

- **画面盲测镜**：把候选的 png **改中性名**（A/B/C），**不告诉它哪张是哪档**，判「两队是否混在中路 / 更像真实 1–5」+ 排序。**只准看图、别猜参数**。
- **判据镜**：**自己重建 wasm、自己复算**全部读数（标出任何对不上的）+ **试证伪**候选的因果机制 + 查 **L1 带余量** / `spacing-sweep` / blast radius。**未能证伪的部分也要写**。

### ④ 主 session 综合

- 四条全过才进短名单：**距离↓ / 目标两根杆↓ / L1 不破 / 盲测说更像**。
- 对抗层修正过的条目**逐条记账**（原结论哪里被改）。

## 硬纪律

1. **先看后量**——第一步是渲图 + 看，不是跑指标。
2. **盲测**——画面裁判不许知道「哪张是哪档」。
3. **距离不是优化目标**——标量有**退化方向**（纯块配置距离最低、画面却是两队叠在球上）。必须配盲测图 + 结构量。
4. **口径齐全**——wasm sha + seed + 时长 + 源码状态。**同 wasm 哈希 ≠ 同一次实验**。
5. **换样本不换判据**；**改门是红线**（`DUR`/`STEP`/默认 seed 集/detector 阈值/统计带一律不动）。
6. **先预注册**再测（预测要能被实测打脸）。
7. **对抗镜自己重建、自己复算**（别信候选的数）。
8. **worktree 隔离**：一候选一 worktree。**别在主仓库那棵树跑引擎实验**——它可能不在 main、有未提交改动 ⇒ 读数不可比。
9. **环境**：用 **paseo agent**（不要用 Claude 自带 `Agent`/`Workflow`——paseo 会话里会被中断）。探针用完即删。

## 已知盲区（如实带过，别掩盖）

- 盲测用的是**轨迹累积图**，「帧间位移」只能反推；单张图判读有噪声——**A/B 分不太开时要报不确定**。
- 判据镜与候选**同工具同方法**，不是完全独立：它抓**口径 / 夸大 / 算术**，抓不到「整套方法都错」。
- 对抗层**不能替代最终人眼验收**：用户看的是 viewer（5min/seed42），不是 90s 探针窗（见 `viewer-scale-vs-probe-scale`）。
- 成本：每候选 = 1 候选 agent + ≥2 对抗 agent。**先拿一条轴把流程跑通**，再加轴。
